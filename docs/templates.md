# 配音模板与预设（M4-P2）

> 2026-09-17 首版。对应 thread `cc-ai-audio-workshop-templates`。
> 产品口径：`docs/product-plan.md` §4.2 的 **P2「模板与预设」**。

## 1. 模板里存什么

配音页「高级」里的一行「模板」：把当前的这几项存成一份可复用的预设（同名覆盖）：

| 字段 | 它影响什么 | 应用时的代价 |
|---|---|---|
| 引擎（model） | 谁来合成 | **需要重新合成**（旧音频是别的引擎的声音） |
| 音色（voice_ref） | 内置默认音色 / 参考音频克隆 | **需要重新合成**（换的是"谁在说"） |
| 兜底规则（auto_normalize） | 数字/年份怎么念（改的是 spoken 文本） | **需要重新合成**（念的是另一套文本） |
| 句间停顿（gap_ms） | 拼装出来的时间轴（句与句之间的静音） | 只**重新导出**即可（已合成的句子还有效） |
| 试听语速（speed） | 只影响试听播放 | 不影响产物 |

应用时按**最重的那一档**处理，状态行写的就是那一档：重录 > 重新导出 > 只影响试听。
判定是纯函数 `templates::apply_effect`（有单测钉住三种档位），界面文案取它的 `note()`——
判定与文案同源，不另写一套。

## 2. 存在哪、坏了怎么办

`~/Documents/音频作坊/templates.json`（与 `settings.json` 同目录，便于一起备份）：

```json
{ "templates": [ { "name": "口播标准", "model": "audio8-tts", "voice_ref": null,
                   "speed": 1.0, "gap_ms": 250, "auto_normalize": true } ] }
```

- 写入是**原子写**（临时文件 + fsync + rename），写到一半断电不会留半截文件；
- 读取时**坏文件报错、不静默当空表**：否则用户下一次"存为"就会把原有模板覆盖掉。
  启动时若读到坏文件，状态行会提示先修好或删掉它；
- 手写的模板只给一部分字段也能读（缺的回落默认：语速 1.0 / 停顿 250 / 兜底开）；
- 同名（忽略大小写）视为同一个模板：覆盖保存，最新的排在下拉最前面。

## 3. 与工程的关系

模板是**输入预设**，不跟着工程走：工程里持久化的是它自己被合成时用的那些值
（`project.json` 的 `model` / `voice_ref` / `gap_ms` / `auto_normalize`），
所以"这个工程是拿哪套设置做出来的"永远看工程自己，而不是看模板当前长什么样。

两个相关细节：

- **停顿**改了不用重录：`Cmd::Assemble` 会带上当前停顿，导出时用它重新拼装并落盘
  （证据：aw-core 的 `assemble_gap_changes_product_duration`——同样两句，gap 0 vs 200ms
  成品时长差 0.2s）；
- **兜底规则**改了必须重录：它进 `project.json`，`load_resumable` 一旦发现开关与工程里
  记的不一致，就不复用旧音频（否则成品里会留下旧读法）。

## 4. 已知边界

- 模板只存这五项；分句参数（标点集/最大句长）目前是常量，不在模板里；
- 没有"模板导出成文件/从文件导入"（`templates.json` 本身可以直接复制），也没有云同步；
- 应用模板时若模板里的引擎在当前模型清单里找不到，引擎索引会被清成"未选择"
  （不静默换成另一个引擎），状态行会提示先选引擎。
