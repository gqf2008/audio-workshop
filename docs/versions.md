# 工程版本：留档 / 对比 / 回滚（M4-P3）

> 2026-09-17 首版。对应 thread `cc-ai-audio-workshop-versions`。
> 产品口径：`docs/product-plan.md` §4.2 的 **P3「工程版本」**。

## 1. 它是什么

配音页「高级」里的「版本」一行：

- **留档**：把**当前界面上**的稿件与设置（引擎 / 音色 / 停顿 / 兜底规则）存成一份版本；
- **版本历史**：列出留过的版本（时间倒序，显示"多久以前 + 多少句"）；
- **对比**：把某个版本与**当前工程**比，给出「设置改了哪几项」+「句子级变化」（只列增删，未变的折叠成一句计数）；
- **回滚**：把该版本的稿件与设置写回工程。

版本文件放在工程目录里：`<工程目录>/.versions/<id>.json`（`id` 是留档时刻的 Unix 毫秒），
所以它跟着工程一起被备份/迁移。

## 2. 为什么不快照音频

一份版本只存 `project.json` 那点内容（几十 KB），**不复制 `sentences/` 与 `out/`**。理由是
回滚之后音频本来就能复用：`load_resumable` 的续作语义是"**按句子文本继承**"——回滚到旧稿后，
文本没变的句子照旧用现成的 wav，变了的句子重录。为此每个版本多存几十 MB 并不换来更多东西。

代价（如实写在这里）：回滚是**内容回滚**，不是"二进制快照回滚"。如果你想拿回某个版本当时
**那一版音频**（例如同一句话、同一个文本但引擎换过），它不会回来——那需要重新合成。

## 3. 回滚会发生什么

回滚是**两步**做的（这一步不能省）：先把当前磁盘工程里"文本相同"的句子音频与状态继承进
版本重建出来的工程（复用 `reuse_done_sentences`，与改稿续作同一条路径），再写回
`project.json`。继承要过**与 `load_resumable` 相同的设置门槛**（模型 / 兜底开关 /
参考音含内容哈希全一致；停顿只影响拼装、不参与）——否则回滚到"同文本但换过模型/音色"
的版本时，会把另一套设置合成的音频标成"这份版本已合成"（界面显示 A、听起来是 B）。少了继承这一步，写回去的就是一份全 `pending` 的工程，下一次
`load_resumable` 会因文本/设置匹配走快路径、原样返回它，"文本相同的句子自动复用"就落空了
（独立复核抓到的正是这条）。状态行会如实报"复用 N 句、还要合成 M 句"。

除此之外，回滚走的是与"改稿"完全相同的那套作废语义，一次做齐：

- 写回 `project.json`（原子写）；
- 界面回灌：稿件、引擎、音色、停顿、兜底开关；
- 作废当前工程与成品（`invalidate_worker_project` + 清 `assembled` + `has_result=false`）、
  作废 BGM 结果、清掉质检分数（分数贴在句子序号上，稿子一变就不再对应）；
- 状态行告诉下一步：**点「开始合成」继续，文本相同的句子会自动复用，不用重录**。

判定"留档下来的工程"用的是与 worker **同一个构造入口**（`new_project_from_inputs`）：
留档的内容就是"点开始合成会用的那一份"，不是另建一个近似对象。

## 4. 坏文件与边界

- 版本文件读不出来（手改坏 / 半截）时，列表**跳过它但把数量说出来**（状态行写
  "N 份留档（M 个文件读不出来，已跳过）"）；一个坏文件不该让整个版本历史打不开，
  也不该被当成"没有版本"。
- 同一毫秒内连续留档不会互相覆盖（id 追加 `-1`、`-2`…）。
- v1 **没有删除版本**（避免破坏性操作）；想清理就直接删 `.versions/` 下的 JSON 文件。
- 不做云同步、不做自动留档；不做跨工程的版本浏览（版本属于它所在的工程目录）。
- **回滚不比较内容**：即使选中的版本与当前工程完全一致，也会照常走一次作废
  （清成品/BGM/质检分数）。代价是多点一次「开始合成」，换来的是行为可预期——
  想做"无损回滚"就得再比一遍全文与设置，收益不值这个复杂度。
- **当前 `project.json` 存在但读不出来时回滚会中止**（不写任何东西）：损坏的工程文件是
  唯一可人工恢复的现场。`Project::load_if_present` 的契约就是"损坏不自动重建、不覆盖"，
  回滚若把 `Err` 当"没有当前工程"继续写盘，就把现场抹掉了。
- 版本 id 只接受我们自己生成的形式（`<毫秒>` 或 `<毫秒>-<序号>`）：界面回传的 id 虽然
  来自列表，但不校验就等于把路径拼接交给调用方（`../..` 能读到工程目录之外）。
- 版本列表在启动、改名、开始合成、留档/回滚这些时刻刷新。
