# 音频作坊 · UI Redesign v1 分屏设计

> 计数口径遵循 `information-architecture.md` §5：顶部 4 个 Tab 合计为 1 个导航组；列表只计 1 个对象；隐藏抽屉和选中后展开的行内操作不计入默认首屏。  
> 每屏最多 8 个语义元素、恰好 1 个主操作、默认 0 个高级参数。

## 1. 全局壳层

四个 Tab 共用同一外壳，避免每个页面重新发明导航、状态和导出：

| 元素 | 作用 | 默认是否可见 |
|---|---|---|
| 顶部主 Tab 组 | 配音 / BGM / 人声分离 / 音乐制作 | 是 |
| 项目条 | 工程名、保存/恢复状态、当前资产摘要 | 是 |
| 任务中心入口 | 显示跨 Tab 的运行、失败、完成数量 | 是；运行/失败时更醒目 |
| 当前 Tab 主画布 | 当前唯一主任务 | 是 |
| 主操作 | 状态驱动的一个高优先级按钮/动作区 | 是 |
| 任务/恢复状态行 | 当前阶段、失败、断点、可继续 | 是；就绪时可弱化 |
| 高级入口 | 打开当前 Tab 的参数抽屉 | 是 |
| 结果/导出条 | 产物摘要与导出次操作 | 仅结果就绪时 |

窗口标题栏和系统窗口按钮只承载操作系统能力，不计入产品密度；不要把场景名、保存状态、引擎版本重复塞进标题栏、项目条和底部状态栏。

## 2. 配音 Tab

### 2.1 首屏元素

默认编辑态建议显示 7 个，完成后最多 8 个。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | 四个 Tab，配音为选中态 |
| 2 | 项目条 | `0921 开箱口播 · 已保存 · 上次留 19/34 句` |
| 3 | 主画布 | 稿件 / 句子二选一的同区画布 |
| 4 | 主操作 | `开始配音`；运行中变为 `停止` |
| 5 | 校听状态行 | `已完成 12/34 · 1 句需重听 · 2 句失败` |
| 6 | 高级入口 | `高级：音色与输出` |
| 7 | 任务中心入口 | `配音 合成中 35%`；空闲时只显示任务图标 |
| 8 | 结果/导出条 | 完成后出现：`成品 03:42 · 导出` |

“稿件 / 句子”切换属于主画布内部工具，不额外计元素。句子行默认只显示序号、文本、状态点；选中后在同一行展开试听、重录、文本编辑和错误详情。

### 2.2 主操作

- 空稿态：主操作是 `导入 / 粘贴稿件`，完成后进入可编辑态。
- 有稿态：主操作是 `开始配音`。如果尚未切句，点击时自动切句并进入排队，不增加第二个主按钮。
- 运行态：同一主操作位变为 `停止`，进度和当前句号只在状态行显示。
- 完成态：主操作位变为 `再生成一版`，导出作为结果条次操作，不抢主任务。
- 失败态：状态行直接显示“第 N 句失败 · 重试”，重试属于状态行内动作。

### 2.3 状态设计

| 状态 | 主画布 | 状态行 | 主操作 |
|---|---|---|---|
| 空态 | 一句说明 + 导入/粘贴入口，不显示空句子列表 | `还没有稿件` | `导入 / 粘贴稿件` |
| 进行中 | 句子列表保留，可切换 Tab；当前句状态可见 | `正在合成第 12/34 句 · 可继续使用其他 Tab` | `停止` |
| 完成 | 句子列表 + 选中句试听；结果条出现 | `34/34 完成 · 成品 03:42` | `再生成一版` |
| 失败 | 失败句靠近列表上方或被状态点强调 | `第 18 句失败 · 可重试` | 状态行内 `重试`；主操作保持 `再生成一版` |
| 可恢复 | 启动后直接显示已有工程 | `上次完成 19/34，可从断点继续` | `继续配音` |

### 2.4 参数位置

配音首屏不显示参数输入框。

高级抽屉分三组：

1. **音色**：音色 / 模型、参考音、许可说明。
2. **交付**：语速、句间停顿、数字与年份规范化。
3. **导出**：WAV / SRT / 两者、输出目录、导出命名。

不进入首屏：seed、毫秒、起始时间刻度、引擎路径、逐句时长小数、内部状态字符串。

### 2.5 与共享系统的关系

- **任务中心**：配音合成是最长的本地任务之一，运行后必须允许切到 BGM / 分离 / 音乐 Tab。
- **导出**：复用配音成品和字幕资产，导出按钮只在成品有效时出现。
- **工程设置**：工程名、保存、恢复、输出目录从项目条或全局设置进入，不再塞进配音主画布。
- **恢复**：工程重开时恢复句子状态、上次选中句和断点；失败句保留原输入和可重试动作。

## 3. BGM Tab

### 3.1 首屏元素

默认生成态建议显示 6 个；有混音结果时最多 8 个。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | BGM 为选中态 |
| 2 | 项目/来源条 | `当前工程：0921 开箱口播 · 混音源：配音成品就绪` |
| 3 | 主画布 | prompt 输入；结果就绪后切换为 BGM / 混音结果摘要 |
| 4 | 主操作 | `生成并混音` |
| 5 | 任务状态行 | `生成第 2/5 段 · 预计还需 1 分 20 秒` |
| 6 | 高级入口 | `高级：时长 / duck / 模型` |
| 7 | 任务中心入口 | 与全局任务中心共用；运行中显示 BGM 状态 |
| 8 | 结果操作区 | 结果就绪时显示音轨切换、试听、导出 |

“BGM / 混音”结果切换属于结果操作区，不额外增加主画布元素。

### 3.2 主操作

- 空态：`写一段描述` 或直接输入 prompt；主操作 `生成并混音`，无 prompt 时禁用并给出一句原因。
- 运行态：同一个主操作位变为 `停止`；不并列出现“生成”“试听”“导出三轨”三个按钮。
- 完成态：主操作位变为 `再生成一版`；结果操作区提供试听、下载和导出。
- 失败态：状态行显示失败段与原因；主操作保持可用，状态行提供 `重试失败段`。

### 3.3 状态设计

| 状态 | 主画布 | 状态行 | 主操作 |
|---|---|---|---|
| 空态 | prompt 输入 + 示例占位 | `写清楚氛围、乐器和是否要人声` | `生成并混音` |
| 进行中 | prompt 折叠为摘要，显示分段阶段和轻量进度 | `生成第 2/5 段 · 可切 Tab` | `停止` |
| 完成 | `BGM / 混音`结果摘要；可试听两轨 | `5 段 · 混音 03:42 · 已完成` | `再生成一版` |
| 失败 | 保留 prompt 和已完成段，标出失败段 | `第 3 段生成失败 · 已完成段已保留` | `重试失败段` |
| 无配音源 | prompt 仍可独立生成 BGM | `未找到配音成品，混音不可用；可先只生成 BGM` | `生成 BGM` |

### 3.4 参数位置

BGM 首屏只保留 prompt 这一个可见输入。

高级抽屉分三组：

1. **生成**：模型、时长、分段长度、是否循环友好。
2. **混音**：是否混入当前配音、duck gain、是否保留 voice / bgm / mixed 三轨。
3. **导出**：输出格式、目录、文件命名。

不进入首屏：精确毫秒、分段索引、模型内部参数、duck 的 dB 原始值（如果需要显示，只显示“弱/中/强”语义档位）。

### 3.5 与共享系统的关系

- BGM 生成本身可以独立；只有“混音”依赖当前工程的配音成品。
- 当前工程没有配音成品时，不阻塞 BGM 生成，只禁用混音并说明原因。
- 任务中心保留每个分段结果，失败后只重试未完成段。
- 导出复用统一导出抽屉，提供“仅 BGM / 仅混音 / 全部产物”。

## 4. 人声分离 Tab

> 重点：当前仓库未发现人声分离后端能力、模型注册或任务接口。本页为设计目标；实现前必须补后端能力，禁止在 UI 中臆造模型名或阈值。

### 4.1 首屏元素

空态建议显示 6 个，结果态最多 8 个。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | 人声分离为选中态 |
| 2 | 项目上下文条 | `保存到当前工程`或`作为独立音频资产导入` |
| 3 | 主画布 | 上传 / 拖入音频区；结果态切换为两轨结果摘要 |
| 4 | 主操作 | `分离人声 / 伴奏` |
| 5 | 任务状态行 | `分析中 42% · 完成后保留两个独立 wav` |
| 6 | 高级入口 | `高级：模型 / 阈值 / 输出` |
| 7 | 任务中心入口 | 与全局任务中心共用 |
| 8 | 结果轨列表 | 人声轨 + 伴奏轨；每轨独立试听、下载 |

结果轨列表计为 1 个列表对象，不把两个轨道的按钮分别计成多个首屏元素。

### 4.2 主操作

- 空态：拖入区是唯一主对象；主操作 `选择音频`，但视觉上仍只突出一个动作。
- 文件就绪：主操作变为 `分离人声 / 伴奏`。
- 运行态：变为 `停止`；状态行显示阶段，不展示算法内部日志。
- 完成态：主操作变为 `重新分离`；两轨列表提供试听和下载。
- 失败态：状态行显示“解码失败 / 模型不可用 / 磁盘不足”等可执行原因，主操作可重试。

### 4.3 状态设计

| 状态 | 主画布 | 状态行 | 主操作 |
|---|---|---|---|
| 空态 | 虚线拖入区，支持点击选择 | `支持本地 wav / mp3 / flac` | `选择音频` |
| 文件就绪 | 文件名、时长、格式摘要 | `已就绪，可分离` | `分离人声 / 伴奏` |
| 进行中 | 文件摘要 + 阶段进度 | `分离中 42% · 可切 Tab` | `停止` |
| 完成 | 人声 / 伴奏两轨结果 | `两轨已生成 · 可分别试听和下载` | `重新分离` |
| 失败 | 保留源文件，不丢输入 | `分离失败：<可执行原因>` | `重试` |
| 能力未就绪 | 明确写“当前版本未接入分离模型” | 不展示假模型选项 | `查看需求状态`（不可发起任务） |

### 4.4 参数位置

首屏只显示拖入区和结果轨列表，显示模型/阈值会立即增加密度。

高级抽屉分三组：

1. **模型**：仅在后端真实注册模型后显示；没有模型时隐藏整组。
2. **处理**：阈值、降噪、保留混响等真实可用选项。
3. **输出**：wav 位深/采样率、输出目录、命名模板。

### 4.5 与共享系统的关系

- 输入文件可保存为工程 `separation_set` 资产，结果轨可被导出器消费。
- 分离任务同样进入全局队列；重开应用后保留源文件和两轨结果。
- 后端未实现时必须用能力门控，不得把 UI 设计当成后端已存在的证据。

## 5. 音乐制作 Tab

### 5.1 首屏元素

默认编辑态建议显示 7 个；完成后最多 8 个。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | 音乐制作为选中态，旁边可有“实验性”小标签 |
| 2 | 项目条 | `当前工程 · 未生成歌曲` |
| 3 | 歌词画布 | 歌词文本编辑，支持段落标记 |
| 4 | 风格输入 | 一句话风格描述 |
| 5 | 主操作 | `生成音乐` |
| 6 | 任务状态行 | `生成中 · 可以先切到其他 Tab` |
| 7 | 高级入口 | `高级：模型 / 步数 / 时长` |
| 8 | 结果条 | 完成时出现：试听、导出、再生成 |

### 5.2 主操作

- 空态：歌词和风格任一为空时，主操作禁用，并在状态行说明缺少什么。
- 就绪态：主操作 `生成音乐`。
- 运行态：主操作变为 `停止`；不显示模型选择、步数、时长。
- 完成态：主操作变为 `再生成一版`；结果条提供试听和导出。
- 失败态：状态行显示失败阶段和可重试操作；歌词与风格不丢。

### 5.3 状态设计

| 状态 | 主画布 | 状态行 | 主操作 |
|---|---|---|---|
| 空态 | 歌词画布与风格输入 | `填写歌词和风格后开始` | `生成音乐`（禁用） |
| 进行中 | 歌词/风格折叠为摘要，显示阶段 | `生成中 35% · 可切 Tab` | `停止` |
| 完成 | 成品摘要和简易播放区 | `歌曲 02:48 · 已生成` | `再生成一版` |
| 失败 | 保留输入，标出失败阶段 | `生成失败：<原因>` | `重试` |
| 实验提示 | 不占据主画布 | 项目条旁显示小标签“实验性” | 不影响主任务 |

### 5.4 参数位置

首屏显示歌词和风格两个输入，不显示模型、步数、时长。

高级抽屉分三组：

1. **模型**：模型选择与许可说明。
2. **生成**：步数、时长、语言、随机性/seed（如果需要保留）。
3. **导出**：WAV / MP3 / 项目导出目录；默认不常驻导出选项。

当前 `feat/m4-song` 里的 `PixelSegmentedControl` 模型选择必须从首屏移入这里；标题从“歌曲 · 彩蛋”改为“音乐制作”，保留“实验性”提示但不把质量长文铺在首屏。

### 5.5 与共享系统的关系

- 歌词、风格、模型选择和生成结果挂到当前工程的 `music_master`。
- 运行中切到其他 Tab 不取消；任务中心可以恢复或重试。
- 导出走统一导出抽屉，不新增第五个主 Tab。

## 6. 四 Tab 共同的失败与恢复原则

| 场景 | 界面行为 | 数据行为 |
|---|---|---|
| 任务失败 | 状态行给出可执行原因，保留输入和已完成产物 | 失败点可重试，不覆盖已有结果 |
| 应用重启 | 恢复当前工程、当前 Tab、选中对象和未完成任务的可见状态 | 从持久化任务记录恢复；无法自动恢复时明确显示“可继续” |
| 切换工程 | 有运行任务或未保存修改时先确认 | 不把前一个工程的产物复制到新工程 |
| 导出失败 | 结果区显示导出失败原因和重试 | 保留源产物，不修改任务结果 |
| 后端不可用 | 当前 Tab 不可开始新任务，已有产物仍可试听/导出 | 不删除本地资产 |
| 能力未实现 | 明确能力未就绪，不显示假模型/假阈值 | 不创建伪任务记录 |

## 7. 视觉密度验收清单

- [ ] 四个 Tab 在任何默认态都可见，且没有任何 Tab 被放进抽屉。
- [ ] 每个 Tab 默认首屏语义元素 ≤ 8；完成态也 ≤ 8。
- [ ] 每个稳定状态只有 1 个主操作。
- [ ] 分辨率 960px 宽时，顶部四个 Tab 不换行、不折叠。
- [ ] 首屏没有 seed、毫秒、时间轴刻度、模型名、步数、duck dB 等实现参数。
- [ ] 每个 Tab 首屏只显示 0~2 个参数输入；高级参数默认 0 个。
- [ ] 任意一行并列操作 ≤ 3 个。
- [ ] 主画布在空、运行、完成、失败四种状态下各自只有一个视觉焦点。
- [ ] 任务运行中允许切换 Tab；切回后状态不丢。
- [ ] 失败任务可从任务中心回到来源 Tab，并定位到重试对象。
