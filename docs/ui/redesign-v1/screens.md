# 音频作坊 · UI Redesign v1.4 分屏设计

> 计数口径遵循 `information-architecture.md` §5：顶部 5 个 Tab 合计为 1 个导航组；列表只计 1 个对象；隐藏抽屉和选中后展开的行内操作不计入默认首屏。
> 每屏最多 8 个语义元素、恰好 1 个主操作、默认 0 个高级参数。
> v1.4 的逐 Tab 状态、点击、拖拽、键盘、失败、恢复和 stale 规则见 `interaction-spec.md`；竞品模式依据见 `competitive-analysis.md`。

## 1. 全局壳层

五个 Tab 共用同一外壳，避免每个页面重新发明导航、状态和导出：

| 元素 | 作用 | 默认是否可见 |
|---|---|---|
| 顶部主 Tab 组 | 配音 / BGM / 人声分离 / 音乐制作 / 音色设计 | 是 |
| 项目条 | 工程名、保存/恢复状态、当前资产摘要 | 是 |
| 任务中心入口 | 显示跨 Tab 的运行、失败、完成数量 | 是；运行/失败时更醒目 |
| 当前 Tab 主画布 | 当前唯一主任务 | 是 |
| 主操作 | 状态驱动的一个高优先级按钮/动作区 | 是 |
| 任务/恢复状态行 | 当前阶段、失败、断点、可继续 | 是；就绪时可弱化 |
| 高级入口 | 打开当前 Tab 的参数抽屉 | 是 |
| 结果/导出条 | 产物摘要与导出次操作 | 仅结果就绪时 |

窗口标题栏和系统窗口按钮只承载操作系统能力，不计入产品密度；不要把场景名、保存状态、引擎版本重复塞进标题栏、项目条和底部状态栏。

BGM、人声分离、音乐制作的结果统一使用轨道行：`[色点] 轨道 / 产物名称 · [试听] [导出]`。需要调 duck、阈值、模型或版本参数时，再展开行或进入高级抽屉。

### 1.1 五 Tab 交互摘要

| Tab | 主按钮点击 / 二次点击 | 跨 Tab 运行 | 取消与失败重试 | Stale 规则 |
|---|---|---|---|---|
| 配音 | 先选当前音色，再 `开始配音` → 运行中 `停止` → 停止后 `继续配音` | 允许；句子状态保留；运行中音色控件锁定 | 单句失败只重录该句；任务级失败继续未完成句 | 文稿 / 音色变更后旧成品 stale，默认导出禁用；换回原音色可恢复 |
| BGM | `生成并混音` → 运行中 `停止` → 完成后 `再生成一版` | 允许；分段进度保留 | 分段失败重试失败段；混音失败只重混 | prompt / 模型变更后旧 BGM stale；只改 duck 则只重新混音 |
| 人声分离 | `分离人声 / 伴奏` → 运行中 `停止` → 完成后 `重新分离` | 允许 | 只支持整任务重试，不做单轨重试 | 更换源文件后旧两轨 stale，默认导出禁用 |
| 音乐制作 | `生成歌曲` → 运行中 `停止` → 完成后 `生成新版本` | 允许；当前版本进度保留 | 重试当前版本或生成新版本 | 改歌词 / 风格只标记草稿有新修改，旧版本仍有效 |
| 音色设计 | `生成试听` → 运行中 `停止` → 完成后 `创建音色` | 允许；试听任务保留 | 试听失败重试试听；保存失败只重试保存 | 文本 / 基础音色 / 参考音变更后试听 stale，保存禁用 |

完整点击、拖拽、键盘、焦点、禁用、确认 / 撤销和逐条验收见 `interaction-spec.md`。可操作演示见 `interactive-prototype.html`。



## 2. 配音 Tab

### 2.1 首屏元素

默认编辑态建议显示 7 个；有结果时最多 8 个。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | 五个 Tab，配音为选中态 |
| 2 | 项目 / 任务条 | 工程名、保存/恢复状态、任务中心入口合并为一条 |
| 3 | 当前音色 | 音色名称 + 来源（内置 / 克隆）；`试听`、`换音色`、`新建音色 →` |
| 4 | 主画布 | 稿件 / 句子二选一的同区画布 |
| 5 | 主操作 | `开始配音`；运行中变为 `停止` |
| 6 | 校听状态行 | `已完成 12/34 · 1 句需重听 · 2 句失败` |
| 7 | 高级入口 | `高级：语速与模型细节` |
| 8 | 结果 / 导出条 | 完成后出现：`成品 03:42 · 导出` |

“当前音色”是一个一等语义元素，内部按钮不额外计元素。音色选择器、模型细节、参考音、语速、句间停顿和导出设置都在抽屉 / 二级面板中，不占首屏。

### 2.2 旁白块（当前音色 + 文本）

当前音色是旁白块头，文本 / 句子直接挂在块体：

```text
● 当前音色  audio8-tts  [内置]
  [试听] [换音色] [新建音色 →]
┌──────────────────────────────┐
│ 欢迎来到今天的开箱视频。      │
│ 这次我把三个版本都带来了。    │
└──────────────────────────────┘
```

- 未选择音色时旁白块头显示 `未选择 · 请先选择音色`；`开始配音` disabled，并在块头下说明 `选择音色后才能开始配音`。
- 已选择时显示音色名称和来源：`内置`（内置模型音色）或 `克隆`（当前工程 / 音色设计保存的 clone voice）。
- `试听` 播放当前音色的短试听；再次点击停止。无音色时 disabled。
- `换音色` 打开 Murf 式音色选择器；搜索 / 筛选 / 卡片默认收起，不常驻五 Tab 首屏。
- `新建音色 →` 切换到音色设计 Tab；保留当前配音稿件和未完成状态，不自动创建音色。
- 运行中：`换音色`、`新建音色 →` disabled，旁白块头显示 `任务运行中，音色不可更换`；当前音色仍可试听。
- 完成后更换音色：选择 `使用此音色` 后旧成品标记 stale，主操作变为 `重新生成`，默认导出禁用；如果切回生成时的同一音色，可恢复未 stale 状态。

### 2.3 音色区（在旁白块内部展开）

**概念纠正（用户纠偏）：换音色 ≠ 换模型。**
音色 = 发声身份，只有两种来源；模型（audio8-tts / index-tts2 / 0.1b / stream…）
是**引擎参数**，放在本页「高级」里，不出现在音色区。

- 入口：旁白块头的 `换音色`（或快捷键 `V`）；选择区在**旁白块内部**展开（2px 边框的子盒，
  把块撑高，稿件仍在同一块内），不是右侧遮罩抽屉、也不是块外的独立盒子、更不是浮层。
- 单一事实来源：参考音频路径为空 = 内置默认音色；非空 = 克隆音色。不引入第二个 mode 状态。
- 内容只有两个来源行，每行 `标题 + 说明 + ✓当前 + 试听 + 使用`：
  1. `内置默认音色` —— `<当前引擎> · 免参考音，开箱可用`；
  2. `参考音频克隆` —— 用一段 5–30 秒干净人声克隆；行下方是该来源的参数（参考音频路径 + 清除）。
- `试听` 走真实链路：用当前引擎合成固定短句；克隆来源额外带上参考音频。
- 参考音频文件不存在/不可读：红字说明并阻止开始配音；路径置空即回到内置音色。
- 出口：`去音色设计 →` 跳音色设计 Tab（不是在这里新建音色）。
- **能力边界**：本机 `GET /v1/audio/voices?model=<id>` 对所有 tts 模型都只返回 `["default"]`，
  即每个引擎只带 1 个内置音色；**多音色库（P4 音色库存档）未接入**，界面上直说，不放假卡片。
- 关闭音色区 / 清除参考音不触发待选变更；改动参考音后旧成品标 stale。

### 2.4 主操作

- 空稿态：主操作是 `导入 / 粘贴稿件`，完成后进入可编辑态。
- 有稿但未选音色：主操作 `开始配音` disabled，原因显示在当前音色控件下。
- 有稿且有音色：主操作 `开始配音`。如果尚未切句，点击时自动切句并进入排队，不增加第二个主按钮。
- 运行态：同一主操作位变为 `停止`，进度和当前句号只在状态行显示；更换音色禁用并解释。
- 完成态：主操作位变为 `再生成一版`；更换音色后变为 `重新生成`；导出作为结果条次操作。
- 失败态：状态行显示“第 N 句失败 · 重试”；失败句的单句重录仍只在句子行展开区出现。

### 2.5 状态设计

| 状态 | 当前音色 | 主画布 | 状态行 | 主操作 |
|---|---|---|---|---|
| 空态 | 未选择，原因可见 | 一句说明 + 导入/粘贴入口 | `还没有稿件 · 请选择音色` | `导入 / 粘贴稿件` |
| 有稿未选音色 | `未选择 · 请先选择音色` | 稿件可编辑 | `选择音色后才能开始配音` | `开始配音` disabled |
| 就绪 | 名称 + 内置 / 克隆 + 试听 / 换音色 | 稿件可编辑 | `已选择音色，可开始配音` | `开始配音` |
| 运行中 | 锁定 + `任务运行中不可更换` | 句子列表保留，可切 Tab | `第 12/34 句 · 可切 Tab` | `停止` |
| 完成 | 当前音色可更换 | 句子列表 + 结果条 | `34/34 完成 · 成品 03:42` | `再生成一版` |
| 完成后换音色 | 新音色 + `待重新生成` | 旧成品保留 | `音色已更换，旧成品为旧版本` | `重新生成` |
| 失败 | 锁定 / 可换按运行状态 | 失败句在列表前排 | `第 18 句失败 · 可重试` | 状态行内 `重试` |
| 可恢复 | 恢复上次音色 | 已完成句保留 | `上次完成 19/34，可从断点继续` | `继续配音` |

### 2.6 参数位置

“当前音色”是首屏必需决策；音色的派生细节放在配音页自己的「高级」区（页内展开，默认收起）。

**配音独有的参数放配音页面上，不进全局抽屉**（全局抽屉只有外观 / 工程 / 服务 / 模型）：

1. **切句**：重新切句（已合成且文本未变的句子复用）。
2. **语音交付**：语速、数字与年份规范化。
3. **任务与导出**：进度 / 试听全篇、WAV / SRT / 两者 / 仅生成、输出目录。

参考音频只作为高级里的临时 `voice_ref` 时，当前音色控件显示 `克隆 · 临时参考`；它不替代音色库保存，也不伪造新的音色资产。

不进入首屏：seed、毫秒、起始时间刻度、引擎路径、逐句时长小数、内部状态字符串。

### 2.7 与共享系统的关系

- **音色设计**：`新建音色 →` 跳转音色设计；保存成功后的 `用于配音` 跳回配音 Tab，聚焦当前音色控件并预选该音色，不自动开始配音。
- **音色资产**：配音首屏和音色选择器读取同一份当前工程音色资产；不在配音高级里重复保存或复制。
- **任务中心**：配音合成是最长的本地任务之一，运行后必须允许切到 BGM / 分离 / 音乐 Tab。
- **导出**：复用配音成品和字幕资产；音色变更后默认导出禁用，旧版本需确认才能导出。
- **恢复**：工程重开时恢复当前音色、句子状态、上次选中句和断点；音色不可用时保留原因并阻止开始。

## 3. BGM Tab

> ✅ **已实现（2026-09-17）**：主操作收敛为一个（生成并混音 → 停止 → 再生成一版）；
> 结果就绪后用**轨道结果区**呈现人声 / BGM / 混音三行（各带试听 + 导出），
> 不再并列"生成 / 试听混音 / 导出三轨"三个按钮；`duck 强度`（弱/中/强 → 系数）进「高级」；
> 改 prompt 即把旧产物标为**旧版本**（仍可试听，重新生成后才算当前结果）。
> 与设计稿的差异：本页把"项目/来源条"并进了状态行（项目名在标题栏，配音源就绪与否
> 由副标题那句说明），因此默认态是 4 个元素而不是 6 个。

### 3.1 首屏元素

默认生成态建议显示 6 个；有混音结果时最多 8 个。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | BGM 为选中态 |
| 2 | 项目/来源条 | `当前工程：0921 开箱口播 · 混音源：配音成品就绪` |
| 3 | 主画布 | prompt 输入；结果就绪后切换为 BGM / 混音结果摘要 |
| 4 | 主操作 | `生成并混音` |
| 5 | 任务状态行 | `生成第 2/5 段 · 预计还需 1 分 20 秒` |
| 6 | 高级入口 | `高级：时长 / duck / 模型` |
| 7 | 任务中心入口 | 与全局任务中心共用；运行中显示 BGM 状态 |
| 8 | 轨道结果区 | 结果就绪时显示 BGM / 混音轨道行、试听、导出 |

“BGM / 混音”结果切换属于结果操作区，不额外增加主画布元素。

### 3.2 主操作

- 空态：`写一段描述` 或直接输入 prompt；主操作 `生成并混音`，无 prompt 时禁用并给出一句原因。
- 运行态：同一个主操作位变为 `停止`；不并列出现“生成”“试听”“导出三轨”三个按钮。
- 完成态：主操作位变为 `再生成一版`；结果操作区提供试听、下载和导出。
- 失败态：状态行显示失败段与原因；主操作保持可用，状态行提供 `重试失败段`。

### 3.3 状态设计

| 状态 | 主画布 | 状态行 | 主操作 |
|---|---|---|---|
| 空态 | prompt 输入 + 示例占位 | `写清楚氛围、乐器和是否要人声` | `生成并混音` |
| 进行中 | prompt 折叠为摘要，显示分段阶段和轻量进度 | `生成第 2/5 段 · 可切 Tab` | `停止` |
| 完成 | `BGM / 混音`结果摘要；可试听两轨 | `5 段 · 混音 03:42 · 已完成` | `再生成一版` |
| 失败 | 保留 prompt 和已完成段，标出失败段 | `第 3 段生成失败 · 已完成段已保留` | `重试失败段` |
| 无配音源 | prompt 仍可独立生成 BGM | `未找到配音成品，混音不可用；可先只生成 BGM` | `生成 BGM` |

### 3.4 参数位置

BGM 首屏只保留 prompt 这一个可见输入。

高级抽屉分三组：

1. **生成**：模型、时长、分段长度、是否循环友好。
2. **混音**：是否混入当前配音、duck gain、是否保留 voice / bgm / mixed 三轨。
3. **导出**：输出格式、目录、文件命名。

不进入首屏：精确毫秒、分段索引、模型内部参数、duck 的 dB 原始值（如果需要显示，只显示“弱/中/强”语义档位）。

### 3.5 与共享系统的关系

- BGM 生成本身可以独立；只有“混音”依赖当前工程的配音成品。
- 当前工程没有配音成品时，不阻塞 BGM 生成，只禁用混音并说明原因。
- 任务中心保留每个分段结果，失败后只重试未完成段。
- 导出复用统一导出抽屉，提供“仅 BGM / 仅混音 / 全部产物”。

## 4. 人声分离 Tab

> ✅ **已实现（2026-09-16）**：后端用 Rust 的 `stem-splitter-core`（htdemucs，ONNX）本地推理，
> 见 `docs/vocal-separation-backend.md`（含实测数据与两个接入硬坑）。
> 实现与本页的差异：① 上游一次出 4 轨，我们用它的 `mix_except` 落成**人声 + 伴奏两轨**；
> ② 上游**没有取消 API**，所以「停止」= 丢弃结果不落盘，UI 文案已如实写明；
> ③ 首次使用要下载约 200MB 模型，副标题与进度里都写了。

### 4.1 首屏元素

**实现口径（2026-09-16，见 `首屏清单.md` §一.5）**：本页默认态 4 个（音频画布 / 主操作 /
高级入口 / 状态行）+ 外壳 3 = 7；结果态加「结果轨列表」= 8。原设计稿把「项目上下文条」
与「任务中心入口」也算在本页，实现里由外壳承担（项目名在标题栏、任务中心在状态栏 chip），
故本页元素更少。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | 人声分离为选中态 |
| 2 | 项目上下文条 | `保存到当前工程`或`作为独立音频资产导入` |
| 3 | 主画布 | 上传 / 拖入音频区；结果态切换为两轨结果摘要 |
| 4 | 主操作 | `分离人声 / 伴奏` |
| 5 | 任务状态行 | `分析中 42% · 完成后保留两个独立 wav` |
| 6 | 高级入口 | `高级：模型 / 阈值 / 输出` |
| 7 | 任务中心入口 | 与全局任务中心共用 |
| 8 | 结果轨列表 | 人声轨 + 伴奏轨；每轨独立试听、下载 |

结果轨列表计为 1 个列表对象，不把两个轨道的按钮分别计成多个首屏元素。

### 4.2 主操作

- 空态：拖入区是唯一主对象；主操作 `选择音频`，但视觉上仍只突出一个动作。
- 文件就绪：主操作变为 `分离人声 / 伴奏`。
- 运行态：变为 `停止`；状态行显示阶段，不展示算法内部日志。
- 完成态：主操作变为 `重新分离`；两轨列表提供试听和下载。
- 失败态：状态行显示“解码失败 / 模型不可用 / 磁盘不足”等可执行原因，主操作可重试。

### 4.3 状态设计

| 状态 | 主画布 | 状态行 | 主操作 |
|---|---|---|---|
| 空态 | 虚线拖入区，支持点击选择 | `支持本地 wav / mp3 / flac` | `选择音频` |
| 文件就绪 | 文件名、时长、格式摘要 | `已就绪，可分离` | `分离人声 / 伴奏` |
| 进行中 | 文件摘要 + 阶段进度 | `分离中 42% · 可切 Tab` | `停止` |
| 完成 | 人声 / 伴奏两轨结果 | `两轨已生成 · 可分别试听和下载` | `重新分离` |
| 失败 | 保留源文件，不丢输入 | `分离失败：<可执行原因>` | `重试` |
| 能力未就绪 | 明确写“当前版本未接入分离模型” | 不展示假模型选项 | `查看需求状态`（不可发起任务） |

### 4.4 参数位置

首屏只显示拖入区和结果轨列表，显示模型/阈值会立即增加密度。

高级抽屉分三组：

1. **模型**：仅在后端真实注册模型后显示；没有模型时隐藏整组。
2. **处理**：阈值、降噪、保留混响等真实可用选项。
3. **输出**：wav 位深/采样率、输出目录、命名模板。

### 4.5 与共享系统的关系

- 输入文件可保存为工程 `separation_set` 资产，结果轨可被导出器消费。
- 分离任务同样进入全局队列；重开应用后保留源文件和两轨结果。
- 后端未实现时必须用能力门控，不得把 UI 设计当成后端已存在的证据。

## 6. 音色设计 Tab

> 现状边界：当前已有单条 `voice_ref` 克隆基础，配音高级中的“参考音频路径”就是这条链路的入口；M4 P4 的“多音色库 / 音色库管理”尚未完整实现。首版只能把“试听”和“当前工程复用”做成真实可用能力，“保存为音色”和预设导出/导入必须走能力门控。

### 6.1 首屏元素

音色设计首屏只做 ElevenLabs Voice Design 式三件事：**Prompt + Text to preview + Generate voice**。默认编辑态 7 个，完成后最多 8 个。

| # | 元素 | 内容 |
|---|---|---|
| 1 | 顶部主 Tab 组 | 音色设计为选中态 |
| 2 | 音色资产上下文条 | `当前工程 · 未保存音色` |
| 3 | 主卡片 · Prompt | 声音描述，例如“温暖克制的年轻女声” |
| 4 | 主卡片 · Text to preview | 预填试听文本 |
| 5 | 主操作 | `生成试听（Generate voice）`；试听完成后变为 `创建音色` |
| 6 | 任务 / 恢复状态行 | `试听生成中 / 试听完成 / 可保存` |
| 7 | 高级与克隆向导入口 | `高级`、`克隆向导 →` |
| 8 | 结果条 | 完成后出现：试听、保存为音色、导出 / 导入预设 |

Prompt 和 Text to preview 是首屏主输入；基础模型、参考音频、参考文本、风格、情绪、seed 不上首屏。

### 6.2 主操作

- 空态：Prompt 或 Text to preview 为空时，`生成试听` disabled。
- 就绪态：点击 `生成试听`，一次只生成一条短试听，不启动完整配音工程。
- 完成后：主操作变为 `创建音色`，把当前 Prompt / 试听结果纳入当前工程音色资产。
- 运行态：主操作变为 `停止`；Prompt 和 Text to preview 可编辑但不自动重跑。
- 能力未就绪：可以试听但 `创建音色` 置灰，说明“多音色保存待 P4”。
- 克隆向导独立：不在 Voice Design 主卡片里塞 Add Voice / Voice Info / Finish up。

### 6.3 状态设计

| 状态 | 主卡片 | 状态行 | 主操作 |
|---|---|---|---|
| 空态 | Prompt / Text to preview 可编辑 | `填写声音描述和试听文本` | `生成试听`（禁用） |
| 就绪 | Prompt + Text to preview 有值 | `已就绪，可生成试听` | `生成试听` |
| 进行中 | 主卡片保持摘要 | `生成试听中 · 可切 Tab` | `停止` |
| 完成 | 试听播放器 + 当前声音摘要 | `试听完成 · 可保存为音色` | `创建音色` |
| 已保存 | 音色资产卡 + `用于配音` | `已保存到当前工程` | `再生成一版` |
| 失败 | 保留 Prompt / Text | `模型不可用 / 保存失败` | `重试` |
| P4 未就绪 | 试听可用，不展示假音色库 | `可试听；多音色保存待实现` | `生成试听` |

### 6.4 克隆向导（二级流程）

入口：音色设计主卡片的 `克隆向导 →`，或音色选择器空态中的 `新建音色 →`。

```text
Add Voice → Voice Info → Finish up
```

- Add Voice：Instant Voice Clone / Professional Voice Clone 两条路径；展示真实支持的样本类型、样本列表和时长进度。
- Voice Info：名称、语言（真实支持时）、许可与用途。
- Finish up：确认、保存到当前工程、可选用于配音。
- 单条 `voice_ref` 只能走 Instant 试听 / 临时复用；Professional Voice Clone、长样本和多音色库必须能力门控。
- 克隆向导不占 Voice Design 首屏；关闭向导弹回 Voice Design 主卡片。

### 6.5 参数位置

首屏只有 Prompt 和 Text to preview 两个主输入。

高级 / 克隆抽屉按能力分组：

1. **Voice Design**：模型、许可、生成参数；只在实际支持时显示。
2. **Instant Clone**：基础音色、参考音频、参考文本；参考文本未接入时只读或隐藏。
3. **Professional / Style**：风格、情绪、seed、样本要求；P4 / 专业克隆未完成时显示未就绪。

不进入首屏：模型名、参考文本、风格标签、seed、样本时长、专业克隆细节、音色文件格式。

### 6.6 与共享系统的关系

- **配音旁白块**：保存后的音色资产出现在配音旁白块的 `换音色` 选择器中；`用于配音` 跳转配音并预选该音色。
- **音色选择器**：使用 Murf 式搜索 / 筛选 / 卡片 / 试听；默认收起，不常驻五 Tab 首屏。
- **任务中心**：Voice Design 试听、Instant / Professional Clone、音色保存都作为任务记录；运行中切 Tab 不取消。
- **导出**：导出/导入音色预设属于资产交付，不等同于音频导出；没有 P4 持久化能力时必须显示未就绪。
- **能力真实性**：单条 `voice_ref` 克隆已有基础；不把 Professional Voice Clone、多音色库和预设互操作写成已完成能力。

## 7. 五 Tab 共同的失败与恢复原则

| 场景 | 界面行为 | 数据行为 |
|---|---|---|
| 任务失败 | 状态行给出可执行原因，保留输入和已完成产物 | 失败点可重试，不覆盖已有结果 |
| 应用重启 | 恢复当前工程、当前 Tab、选中对象和未完成任务的可见状态 | 从持久化任务记录恢复；无法自动恢复时明确显示“可继续” |
| 切换工程 | 有运行任务或未保存修改时先确认 | 不把前一个工程的产物复制到新工程 |
| 导出失败 | 结果区显示导出失败原因和重试 | 保留源产物，不修改任务结果 |
| 后端不可用 | 当前 Tab 不可开始新任务，已有产物仍可试听/导出 | 不删除本地资产 |
| 能力未实现 | 明确能力未就绪，不显示假模型/假阈值 | 不创建伪任务记录 |
