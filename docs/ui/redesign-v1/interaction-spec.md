# 音频作坊 · UI Redesign v1.4 交互规范

> 适用范围：五个主 Tab（配音 / BGM / 人声分离 / 音乐制作 / 音色设计）及其共享任务中心、导出抽屉和高级抽屉。  
> 实现边界：本文只定义设计契约，不修改 Rust / Slint，不提交代码。  
> 可点击演示：`interactive-prototype.html`。静态线框标注见 `wireframes.html`。
> 竞品模式依据：`competitive-analysis.md`。

## 1. 全局交互约定

### 1.1 点击与二次点击

| 对象 | 第一次点击 | 第二次点击 / 双击 | 备注 |
|---|---|---|---|
| 顶部 Tab | 切换当前 Tab | 无 | 不取消后台任务 |
| 句子行 / 版本行 / 音轨行 | 选中并展开次级操作 | 对已选中行再次点击 = 试听 / 播放 | 不依赖严格的系统双击间隔；第二次点击同一选中对象即可 |
| `试听` 按钮 | 播放 | 再次点击 `停止` | 播放按钮始终有明确文案 |
| 主操作按钮 | 开始主任务 | 运行中再次点击 = 停止 / 暂停 | 同一位置只存在一个主操作 |
| `清空` | 第一次点击打开确认 | 确认按钮第二次确认 | 确认后保留 5 秒撤销 |
| 删除音色 / 删除音乐版本 | 第一次点击打开确认 | 确认按钮第二次确认 | 删除后 5 秒撤销，采用软删除 |
| 任务中心 `取消` | 第一次点击变为 `确认取消` | 第二次点击取消任务 | 2 秒后恢复原文案 |
| 抽屉遮罩 | 关闭抽屉 | 无 | `Esc` 同样关闭 |

### 1.2 主按钮状态

主按钮必须来自同一语义位置，不得通过新增并列按钮表达状态变化。

| 状态 | 文案 | disabled | 点击结果 |
|---|---|---|---|
| 空态 / 未满足前置条件 | 场景指定（如 `导入 / 粘贴稿件`） | 满足条件前禁用 | 不执行；在靠近按钮处显示原因 |
| 就绪 | `开始配音` / `生成并混音` / `分离人声 / 伴奏` / `生成音乐` / `生成试听` | 否 | 进入 `running`，抽屉自动收起 |
| 运行中 | `停止` | 否，可取消任务 | 停止当前任务并保留可恢复产物 |
| 完成 | `再生成一版` / `重新分离` / `生成新版本` / `创建音色` | 否 | 创建新版本或进入下一阶段 |
| 失败 | `重试` 或 `重试失败段` | 否 | 按粒度重试 |
| 恢复 | `继续配音` / `继续生成` / `继续分离` | 否 | 从保存的进度点继续 |

### 1.3 运行中与跨 Tab

1. 点击主操作并进入运行后，高级抽屉自动收起；运行状态留在当前 Tab 状态行和全局任务中心。
2. 运行中允许切换任意主 Tab；切换 Tab 不取消、不暂停、不重排队任务。
3. 任务中心必须显示：来源 Tab、任务名称、状态、进度、结果版本 / 资产、可执行动作。
4. 任务中心动作：
   - `打开`：回到来源 Tab，并聚焦运行对象。
   - `取消`：可取消任务走二次确认；不可取消任务显示禁用原因。
   - `重试`：失败任务按任务粒度重试。
5. 取消后状态为 `recoverable`，不是完成；保留已完成的句子、分段或版本。
6. 应用重启后，运行中任务若没有真实 worker，显示为 `已中断，可继续`，不能继续显示转圈。

### 1.4 键盘

| 快捷键 | 行为 | 适用范围 |
|---|---|---|
| `Cmd/Ctrl + 1..5` | 切换五个主 Tab | 全局 |
| `Cmd/Ctrl + Enter` | 触发当前主操作 / 继续 | 全局 |
| `Space` | 播放 / 暂停当前选中结果 | 试听区；输入框获得焦点时不拦截 |
| `↑ / ↓` | 移动句子 / 音轨 / 版本选择 | 列表 |
| `Enter` | 打开当前选择项或开始试听 | 列表 |
| `R` | 重试当前失败对象 | 错误状态 |
| `Esc` | 关闭抽屉 / 对话框 / 停止当前试听 | 全局 |
| `V` | 配音首屏打开音色选择器 | 配音 |
| `P` | 试听 / 停止当前配音音色 | 配音 |
| `N` | 从配音跳转音色设计新建音色 | 配音 |
| `Tab` / `Shift+Tab` | 按视觉顺序移动焦点 | 全局 |

### 1.5 焦点

- 顶部 Tab 按视觉顺序进入焦点；当前 Tab 有选中态。
- 抽屉打开后焦点进入抽屉标题 / 第一个可编辑控件；关闭后焦点返回触发按钮。
- 主操作完成后焦点留在主操作位；结果条出现时不抢焦点。
- 状态行、错误和完成 toast 使用 `aria-live` 等价语义；错误不能只靠颜色。
- 所有可点击区域最小高度 44px；键盘焦点必须有 2px 可见轮廓。

### 1.6 禁用与验证

- 禁用按钮保留可见，不禁用整个页面；相邻状态行必须解释原因。
- 表单在失去焦点和提交时验证；错误显示在字段下方。
- 文件拖入时先做扩展名 / 可读性预检；具体时长、内存和模型限制由后端返回，不在 UI 臆造上限。
- 后端不可用时，已有结果仍可试听、导出；只禁用新任务。
- 能力未就绪时显示“不可用原因 + 未来动作”，不创建伪任务。

### 1.7 Stale 规则

“stale”表示输入已经改变，现有结果不再是当前输入的产物。

| 场景 | 结果处理 | 主操作 | 导出 |
|---|---|---|---|
| 配音稿件 / 音色 / 语速改变 | 旧成品标记 `旧版本` | `重新生成` | 默认禁用；溢出菜单可确认后导出旧版本 |
| BGM prompt / 模型改变 | 旧 BGM 标记 `旧版本` | `重新生成` | 默认禁用；旧版本需确认导出 |
| BGM duck gain 改变 | 不重新生成 BGM，进入 `重新混音` | `应用并重新混音` | 混音旧版本确认可导出 |
| 人声分离源文件改变 | 旧两轨标记 `旧版本` | `重新分离` | 旧版本需确认导出 |
| 音乐歌词 / 风格改变 | 旧音乐版本仍有效，作为版本保留 | `生成新版本` | 当前选中旧版本仍可导出 |
| 音色设计试听文本 / 参考音改变 | 试听标记 `已过期` | `重新生成试听` | 保存为音色禁用，直到重新试听 |

### 1.8 确认与撤销

- 确认弹窗只用于破坏性动作：清空稿件、覆盖同名音色、删除版本、替换源文件、取消并丢弃当前结果。
- 软删除 / 清空动作提供 5 秒撤销 bar：`已清空 · 撤销`、`已删除版本 v2 · 撤销`。
- 取消任务不弹全屏确认；在任务中心二次点击 `确认取消` 即可。
- 撤销期间新操作会立即提交并关闭撤销窗口。

### 1.9 轨道行

BGM、人声分离、音乐制作的结果统一使用轨道行：

```text
[色点] 轨道 / 产物名称  [试听] [导出]
```

- 第一次点击轨道行：选中并显示轨道级次操作。
- 第二次点击同一轨道行：播放 / 停止试听。
- `试听` 按钮独立可用，点击后变为 `停止`。
- 轨道行不铺高级参数；需要时点击 `更多` / `高级`，或展开行内摘要。
- 轨道颜色只做辅助识别，必须同时显示名称；没有音轨时显示空态，不伪造占位音轨。
- 未来接入统一 timeline 时，轨道行应能映射为 timeline lane，但 v1.4 不实现 DAW 级编辑。

## 2. 配音 Tab

### 2.1 状态机

配音必须以“当前音色已选”为前置条件。

```text
empty / text-missing
  → text-ready + voice-missing       // 开始配音 disabled
  → text-ready + voice-selected
  → running                          // 音色控件锁定
  → stopping
  → complete / partial-failed
  → stale                            // 完成后更换音色或修改文本
       ↘ recoverable → running
       ↘ failed → retry
```

| 状态 | 当前音色 | 主按钮 | 状态行 |
|---|---|---|---|
| text-missing | 可选，未选时说明原因 | `导入 / 粘贴稿件` 或 disabled | `还没有句子` |
| voice-missing | `未选择 · 请先选择音色` | `开始配音` disabled | `选择音色后才能开始配音` |
| ready | 名称 + 来源 + `试听` / `换音色` | `开始配音` | `已选音色，可开始配音` |
| running | 锁定，`任务运行中不可更换` | `停止` | `第 N/M 句 · 35% · 可切 Tab` |
| stopping | 锁定 | `停止中…` disabled | `正在结束当前句…` |
| complete | 当前音色可更换 | `再生成一版` | `M/M 完成 · 成品 03:42` |
| stale | 新音色 + `待重新生成` | `重新生成` | `音色已更换，旧成品为旧版本` |
| partial-failed | 当前音色可更换 | `继续配音` | `1 句失败 · 其余已完成` |
| recoverable | 恢复上次音色 | `继续配音` | `上次完成 19/34` |

### 2.2 旁白块头（当前音色 + 文本）

首屏必须有一个 ElevenLabs 式旁白块：块头是彩色 dot + 当前音色，文本 / 句子直接挂在块体：

```text
● 当前音色  <name>  [内置 / 克隆]
  [试听] [换音色] [新建音色 →]
┌──────────────────────────────┐
│ Text / Sentence block         │
└──────────────────────────────┘
```

可点击区域与行为：

| 区域 | 第一次点击 / 二次点击 | 键盘 | 禁用条件 |
|---|---|---|---|
| 当前音色控件本体 | 聚焦控件；不直接切换音色 | `Enter` 打开音色选择器 | running / stopping |
| `试听` | 播放当前音色短试听；再次点击停止 | `P` | 无音色 / 音频设备不可用 |
| `换音色` | 打开音色选择器 | `V` | running / stopping |
| `新建音色 →` | 跳转音色设计 Tab | `N` | running / stopping |
| 音色名称 / 来源 | 显示 `内置` 或 `克隆`，不打开菜单 | 焦点在控件时可读屏 | 未选时显示原因 |

- 没有选择音色时，旁白块头显示 `未选择 · 请先选择音色`，并在块头下显示 `选择音色后才能开始配音`。
- 主按钮 disabled 的原因优先级：运行中 > 无音色 > 无稿件；只显示当前最重要原因，避免堆叠错误。
- 运行中只锁定替换音色；旁白块保留文本 / 句子内容，`试听` 当前音色仍可播放，但不可打开选择器或跳转新建音色。
- 完成后更换音色：点击 `使用此音色` 后旧成品标记 stale，主按钮变为 `重新生成`，默认导出禁用。切回生成时的同一音色后，若无其它输入变化，stale 恢复。
- 高级抽屉中的“参考音频临时覆盖”会使当前音色来源变为 `克隆 · 临时参考`，并遵循同样的 stale 规则。

### 2.3 音色区（页内展开；换音色 ≠ 换模型）

`换音色` 或 `V` 在**旁白块内部**展开音色区（2px 边框子盒，把块撑高），默认收起。

- 结构：两个来源行（`内置默认音色` / `参考音频克隆`）+ 克隆来源的参考音频参数行。
- 每行：`标题 + 说明 + ✓当前 + 试听 + 使用`；`使用` 在当前行上禁用（文案 `正在用`）。
- `内置默认音色` 行：点击 `使用内置音色` = 清空参考音频路径（切回内置）。
- `参考音频克隆` 行：参考音频路径非空才可用；路径是这一行的参数，不是独立开关。
- `试听`：用当前引擎合成固定短句；克隆来源带参考音频。任务运行中 `试听` 仍可用，`使用` 与路径编辑禁用。
- 参考音频路径非法（文件不存在/不可读）：行内红字说明 + `开始配音` disabled，原因只在旁白块头下显示一条。
- 单一事实来源：路径为空 = 内置、非空 = 克隆；不设第二份 mode 状态，避免两处漂移。
- 引擎（模型）**不在**这里：它在同页 `高级` 区的 `引擎` 下拉里，改动走 `model-changed` 的失效规则。
- `去音色设计 →`：跳音色设计 Tab；本区不承担“新建音色”。
- 能力门控：`/v1/audio/voices` 只返回 `default` → 内置组只有 1 条；多音色库未接入，写明而不造假卡片。

### 2.4 键盘、焦点和二次点击

| 操作 | 结果 |
|---|---|
| `V` | 打开音色选择器 |
| `P` | 试听 / 停止当前音色 |
| `N` | 跳转音色设计并保留当前配音草稿 |
| `Enter` | 当前音色控件聚焦时打开选择器；列表行聚焦时应用待选 |
| `Space` | 音色列表行试听 / 停止 |
| `↓ / ↑` | 音色列表移动 |
| `Esc` | 关闭选择器，焦点回到 `换音色` |
| `Tab` / `Shift+Tab` | 当前音色控件 → `试听` → `换音色` → `新建音色` 顺序移动 |

- 当前音色控件必须作为一组可朗读对象；读屏文本包含名称、来源、是否可用、试听动作和换音色动作。
- 选择器列表行使用 `aria-selected` 等价状态；当前音色和待选音色是不同视觉状态。
- 运行中控件整体显示锁定语义，`换音色` 和 `新建音色` 为 disabled；禁用原因可由读屏读出。
- 所有可点击目标高度 ≥44px；`Esc` 后焦点回到 `换音色`，不能丢到页面根节点。

### 2.5 失败、取消与恢复

- 音色不可用：当前音色控件显示 `不可用`，`开始配音` disabled；可在选择器中换音色或重新定位参考音。
- 单句失败：句子行展开区的 `重录` 只重试该句，不影响当前音色。
- 任务级失败：状态行显示服务 / 磁盘原因；`继续配音` 从失败句继续，当前音色保持不变。
- 运行中取消：已完成句保留，音色锁定解除；恢复后仍使用取消前音色，除非用户重新选择。
- 恢复：工程重开恢复上次音色和音色来源；如果资产缺失或模型不可用，保留名称但标记不可用，禁止开始。
- 确认 / 撤销：清空稿件、覆盖已有音色资产、替换临时参考音都需要确认；软删除 / 清空支持 5 秒撤销。

## 3. BGM Tab

### 3.1 状态机

```text
empty → editing → ready → generating → mixing → complete
                                      ↘ failed-segment → retry-segment / remaining
                                      ↘ failed-mix → retry-mix
                                      ↘ stale → regenerate / re-mix
```

| 状态 | 主画布 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | prompt 空态 | `生成并混音` 禁用 | `写一段音乐描述` |
| ready | prompt 可编辑 | `生成并混音` | `等待生成` |
| generating | prompt 摘要 + 分段进度 | `停止` | `第 2/5 段 · 可切 Tab` |
| mixing | BGM 已完成，混音中 | `停止混音` | `正在按句子时间轴 duck` |
| complete | BGM / 混音结果 | `再生成一版` | `5 段 · 混音 03:42` |
| failed-segment | 已完成段保留，失败段标记 | `重试失败段` | `第 3 段失败` |
| failed-mix | BGM 保留，混音失败 | `重新混音` | `混音失败：<原因>` |
| stale | prompt 或模型变了 | `重新生成` | `当前结果是旧版本` |

### 3.2 点击、二次点击与高级 duck

- `prompt`：单次点击聚焦；编辑后不再自动生成。
- 主按钮：运行中第二次点击 = 停止；停止发生在当前分段完成后。
- 结果轨：第一次点击选中 `BGM` 或 `混音`；第二次点击已选中轨 = 试听。
- `高级`：打开生成、混音、导出三组。
- `duck gain`：拖动滑杆只更新当前草稿与语义值（弱 / 中 / 强），不立即重算；点击 `应用并重新混音` 后运行混音任务并自动收起抽屉。
- `混音源` 未就绪：duck 组可见但禁用，并说明“需要先完成配音成品”。
- 失败重试：生成失败按分段重试；混音失败只重试混音，不重新生成 BGM。
- 取消：停止后保留已完成段；再次点击准备继续时从第一个未完成段开始。
- stale：prompt 改变后旧 BGM 标记旧版本；如果只改 duck，则旧 BGM 仍有效，只重新混音。

## 4. 人声分离 Tab

### 4.1 状态机与能力门控

```text
empty → validating → ready → separating → complete
                               ↘ failed → retry-task
capability = ready | unsupported | error
unsupported: empty / validating 可操作，但不能进入 separating
```

| 状态 | 拖入区 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | 可点击 / 拖入 | `选择音频` | `wav / mp3 / flac` |
| validating | 文件名 + 校验中 | `校验中…` 禁用 | `只做扩展名和可读性预检` |
| ready | 文件名、格式、大小摘要 | `分离人声 / 伴奏` | `源文件已就绪` |
| separating | 文件摘要 + 阶段进度 | `停止` | `分离中 42% · 可切 Tab` |
| complete | 人声 / 伴奏两轨 | `重新分离` | `两轨已生成` |
| failed | 保留源文件 | `重试` | `解码失败 / 模型不可用 / 磁盘不足` |
| unsupported | 可选择但不可分离 | `分离人声 / 伴奏` 禁用 | `后端能力未接入，不会创建任务` |

### 4.2 点击、拖拽、键盘与取消

- 拖拽：`dragenter` 高亮拖入区；`drop` 后只读取文件元数据，不立刻上传执行。
- 点击拖入区：打开文件选择；选择后进入 `validating`。
- 结果轨：第一次点击选中 `vocals` 或 `accompaniment`；第二次点击同一轨试听。
- 键盘：`V` 选择 vocals，`A` 选择 accompaniment，`Space` 播放 / 暂停，`R` 重试。
- 取消：点击 `停止`，当前任务进入 `cancelled`；源文件保留，临时两轨不作为完成结果。
- 失败粒度：整个分离任务重试，不做单轨重试；两轨必须属于同一次模型运行。
- 恢复：保存源文件路径和任务断点；重启后如果路径不可读，显示 `重新定位源文件`。
- stale：更换或重新选择源文件后，旧两轨标记旧版本；默认禁用导出，溢出菜单可确认旧版本导出。
- 能力未就绪：按钮保持可见但 disabled；任务中心不新增任务；高级抽屉模型组只读说明。

## 5. 音乐制作 Tab

### 5.1 状态机与版本

```text
empty → editing → ready → generating → version-ready
                                      ↘ failed-version
                                      ↘ cancelled-version
editing after version-ready → draft-changed → generate new version
```

| 状态 | 主画布 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | 歌词 / 风格空 | `生成音乐` 禁用 | `填写歌词和风格` |
| ready | 两个输入有值 | `生成音乐` | `可生成 v1` |
| generating | 输入摘要 + 进度 | `停止` | `生成中 35% · 可切 Tab` |
| version-ready | 版本列表 + 选中版本 | `生成新版本` | `v1 已生成` |
| failed-version | 保留输入与历史版本 | `重试当前版本` | `v2 生成失败` |
| draft-changed | 输入已改，旧版本仍有效 | `生成新版本` | `有未生成的新修改` |

### 5.2 点击、版本、取消与恢复

- 点击 `生成音乐` 创建新版本，不覆盖历史版本。
- 版本行第一次点击选中；第二次点击同一版本试听。
- `预览` 按钮播放当前版本；切换版本时停止上一版本试听。
- 取消：停止当前版本生成；半成品版本标记为 `failed / cancelled`，不进入可导出版本。
- 重试：`重试当前版本` 使用同一输入和同一 seed 重跑；`生成新版本` 使用新 seed。
- stale：歌词 / 风格变化只标记草稿已更新，不使旧版本失效；导出默认导出当前选中的完整版本。
- 恢复：历史完整版本、选中版本、未完成版本状态均持久化。
- 删除版本：第一次点击打开确认，第二次确认删除；软删除并保留 5 秒撤销。

## 6. 音色设计 Tab

### 6.1 状态机与三件事

主卡片固定采用 ElevenLabs Voice Design 的三件事：

```text
Prompt
  + Text to preview
  → Generate voice
  → preview-ready
  → create voice / use-in-dub
```

```text
empty
  → ready
  → preview-running
  → preview-ready
  → saved
       ↘ preview-stale
       ↘ failed
capability-voice-library = ready | unsupported | error
```

| 状态 | 主卡片 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | Prompt / Text to preview 可编辑 | `生成试听` disabled | `填写声音描述和试听文本` |
| ready | 两个主输入有值 | `生成试听` | `已就绪，可生成试听` |
| preview-running | 输入折叠为摘要 | `停止` | `生成试听中 · 可切 Tab` |
| preview-ready | 试听播放器 + 当前声音摘要 | `创建音色` | `试听完成 · 可保存` |
| preview-stale | 旧试听标记过期 | `重新生成试听` | `输入已改，请重新试听` |
| saved | 音色资产卡 + `用于配音` | `再生成一版` | `已保存到当前工程` |
| failed | 保留 Prompt / Text | `重试` | `模型不可用 / 保存失败` |
| unsupported | 试听可用，保存区禁用 | `生成试听` | `可试听；多音色保存待 P4` |

### 6.2 主卡片交互

- `Prompt`：单次点击聚焦；编辑后旧试听立即 stale。
- `Text to preview`：默认预填；编辑后旧试听立即 stale。
- `Generate voice / 生成试听`：运行中第二次点击 = 停止；完成后主按钮变成 `创建音色`。
- 结果条：`试听` 单次播放 / 再次点击停止；`保存为音色` 受 P4 能力门控；`预设` 菜单包含导出 / 导入，未实现时禁用。
- 克隆向导入口：`克隆向导 →`，不把 Add Voice / Voice Info / Finish up 塞进主卡片。
- 高级：模型、参考文本、风格、情绪、seed 只在后端真实支持时显示；没有能力时整组未就绪。

### 6.3 克隆向导

克隆向导是音色设计的二级流程：

```text
Add Voice → Voice Info → Finish up
```

- Add Voice：`Instant Voice Clone` / `Professional Voice Clone` 两条路径；显示真实支持的样本列表与时长进度。
- Voice Info：名称、语言（真实支持时）、许可与用途。
- Finish up：保存到当前工程，可选 `用于配音`。
- 单条 `voice_ref` 只承诺 Instant 试听 / 临时复用；Professional Clone、长样本、多音色库在 P4 未完成时必须 disabled。
- 向导关闭后回到主卡片，保留 Prompt 和 Text to preview。

### 6.4 键盘、焦点与二次点击

| 操作 | 结果 |
|---|---|
| `Tab` | Prompt → Text to preview → Generate voice → 克隆向导 |
| `Cmd/Ctrl+Enter` | 触发 `生成试听` / 停止 |
| `Space` | 试听 / 停止试听 |
| `Esc` | 关闭克隆向导或高级抽屉，返回主卡片 |
| 卡片行第一次点击 | 选中克隆路径 / 样本 |
| 卡片行第二次点击 | 试听样本或切换选中 |

- 主按钮 disabled 时，Prompt 或 Text to preview 的错误靠近对应字段。
- 克隆向导每一步有明确标题、返回、下一步和完成后的撤销 / 删除入口。
- 读屏文本必须说明“Voice Design 主卡片”和“克隆向导”是两个不同流程。

### 6.5 与配音旁白块的关系

- 保存成功后，音色资产出现在配音旁白块头的 `换音色` 选择器中。
- 点击 `用于配音`：切换到配音 Tab，聚焦旁白块头并预选该音色，不自动开始配音。
- Voice Design 只处理声音设计；配音文本和句子仍由配音 Tab 的旁白块管理。

## 7. 完整流程脚本

### 7.1 配音

1. 当前音色为空 → 主按钮 `开始配音` disabled，控件下显示 `选择音色后才能开始配音`。
2. 点击 `换音色` → 选择器打开；在内置音色中选择 `audio8-tts`，点击 `使用此音色`；控件变为 `audio8-tts [内置]`。
3. 输入或粘贴稿件 → 主按钮 `开始配音` 启用。
4. 点击主按钮 → 抽屉自动收起，按钮变 `停止`，状态行显示 `第 1/N 句，0%`；当前音色控件显示锁定。
5. 切换到 BGM Tab → 配音任务继续，任务中心显示 `配音 · 运行中`。
6. 切回配音 → 恢复句子列表和进度；尝试 `换音色` 时按钮 disabled，并说明“任务运行中不可更换音色”。
7. 再次点击主按钮 → `停止`；状态变为 `可继续`，已完成句保留。
8. 点击 `继续配音` 或演示控制 `完成` → 结果条出现。
9. 完成后点击 `换音色` → 选择另一个音色并使用 → 主按钮变 `重新生成`，旧成品标记 stale，导出默认禁用。
10. 切回生成时的音色 → stale 清除；点击 `导出` → 导出抽屉打开；确认导出后关闭并显示成功 toast。

### 7.2 BGM

1. 输入 prompt → `生成并混音` 启用。
2. 点击生成 → 按钮变 `停止`；状态显示分段进度。
3. 完成后结果区出现 `BGM` / `混音` 两轨；点击轨行两次或点击播放按钮试听。
4. 点击 `高级` → 调整 `duck` → 点击 `应用并重新混音`；抽屉自动关闭，状态显示重新混音。
5. 混音完成后点击 `导出` → 选择 `仅 BGM / 仅混音 / 全部` 并确认。

### 7.3 人声分离

1. 拖入 wav 文件 → 进入校验，显示文件名与格式。
2. 校验通过 → `分离人声 / 伴奏` 启用。
3. 点击主按钮 → 运行进度；切 Tab 不取消。
4. 完成 → 两轨出现；选择 vocals 或 accompaniment 后试听。
5. 切换 `capability = unsupported` → 新任务主按钮禁用，状态说明后端未接入；无伪任务。
6. 切回 `ready` → 已完成的旧结果仍可试听 / 导出，新任务重新启用。

### 7.4 音乐制作

1. 输入歌词和风格 → `生成音乐` 启用。
2. 点击生成 → 运行中切换 Tab，任务中心显示 `音乐制作 · 生成中`。
3. 完成 → 出现 `v1` 版本并自动选中。
4. 修改歌词 → 旧 v1 仍有效，状态显示 `有未生成的新修改`。
5. 再点击生成 → 创建 `v2`，自动选中新版本。
6. 点击 `导出` → 导出当前选中版本。

### 7.5 音色设计

1. Prompt 输入声音描述；Text to preview 默认预填。
2. 点击 `生成试听` → 按钮变 `停止`，状态显示生成中。
3. 完成后主按钮变 `创建音色`；点击结果条 `试听` 播放。
4. P4 `unsupported`：`创建音色` 和 `用于配音` 禁用，显示“可试听，多音色保存待 P4”。
5. P4 `ready`：点击 `创建音色` → 保存成功，出现 `用于配音`。
6. 点击 `用于配音` → 跳转配音 Tab，聚焦旁白块头并预选该音色；不打开高级抽屉，也不自动开始配音。
7. 点击 `克隆向导 →` → 进入 `Add Voice → Voice Info → Finish up`；Professional Clone 在能力未就绪时 disabled。
