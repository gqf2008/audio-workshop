# 音频作坊 · UI Redesign v1.2 交互规范

> 适用范围：五个主 Tab（配音 / BGM / 人声分离 / 音乐制作 / 音色设计）及其共享任务中心、导出抽屉和高级抽屉。  
> 实现边界：本文只定义设计契约，不修改 Rust / Slint，不提交代码。  
> 可点击演示：`interactive-prototype.html`。静态线框标注见 `wireframes.html`。

## 1. 全局交互约定

### 1.1 点击与二次点击

| 对象 | 第一次点击 | 第二次点击 / 双击 | 备注 |
|---|---|---|---|
| 顶部 Tab | 切换当前 Tab | 无 | 不取消后台任务 |
| 句子行 / 版本行 / 音轨行 | 选中并展开次级操作 | 对已选中行再次点击 = 试听 / 播放 | 不依赖严格的系统双击间隔；第二次点击同一选中对象即可 |
| `试听` 按钮 | 播放 | 再次点击 `停止` | 播放按钮始终有明确文案 |
| 主操作按钮 | 开始主任务 | 运行中再次点击 = 停止 / 暂停 | 同一位置只存在一个主操作 |
| `清空` | 第一次点击打开确认 | 确认按钮第二次确认 | 确认后保留 5 秒撤销 |
| 删除音色 / 删除音乐版本 | 第一次点击打开确认 | 确认按钮第二次确认 | 删除后 5 秒撤销，采用软删除 |
| 任务中心 `取消` | 第一次点击变为 `确认取消` | 第二次点击取消任务 | 2 秒后恢复原文案 |
| 抽屉遮罩 | 关闭抽屉 | 无 | `Esc` 同样关闭 |

### 1.2 主按钮状态

主按钮必须来自同一语义位置，不得通过新增并列按钮表达状态变化。

| 状态 | 文案 | disabled | 点击结果 |
|---|---|---|---|
| 空态 / 未满足前置条件 | 场景指定（如 `导入 / 粘贴稿件`） | 满足条件前禁用 | 不执行；在靠近按钮处显示原因 |
| 就绪 | `开始配音` / `生成并混音` / `分离人声 / 伴奏` / `生成音乐` / `生成试听` | 否 | 进入 `running`，抽屉自动收起 |
| 运行中 | `停止` | 否，可取消任务 | 停止当前任务并保留可恢复产物 |
| 完成 | `再生成一版` / `重新分离` / `生成新版本` / `创建音色` | 否 | 创建新版本或进入下一阶段 |
| 失败 | `重试` 或 `重试失败段` | 否 | 按粒度重试 |
| 恢复 | `继续配音` / `继续生成` / `继续分离` | 否 | 从保存的进度点继续 |

### 1.3 运行中与跨 Tab

1. 点击主操作并进入运行后，高级抽屉自动收起；运行状态留在当前 Tab 状态行和全局任务中心。
2. 运行中允许切换任意主 Tab；切换 Tab 不取消、不暂停、不重排队任务。
3. 任务中心必须显示：来源 Tab、任务名称、状态、进度、结果版本 / 资产、可执行动作。
4. 任务中心动作：
   - `打开`：回到来源 Tab，并聚焦运行对象。
   - `取消`：可取消任务走二次确认；不可取消任务显示禁用原因。
   - `重试`：失败任务按任务粒度重试。
5. 取消后状态为 `recoverable`，不是完成；保留已完成的句子、分段或版本。
6. 应用重启后，运行中任务若没有真实 worker，显示为 `已中断，可继续`，不能继续显示转圈。

### 1.4 键盘

| 快捷键 | 行为 | 适用范围 |
|---|---|---|
| `Cmd/Ctrl + 1..5` | 切换五个主 Tab | 全局 |
| `Cmd/Ctrl + Enter` | 触发当前主操作 / 继续 | 全局 |
| `Space` | 播放 / 暂停当前选中结果 | 试听区；输入框获得焦点时不拦截 |
| `↑ / ↓` | 移动句子 / 音轨 / 版本选择 | 列表 |
| `Enter` | 打开当前选择项或开始试听 | 列表 |
| `R` | 重试当前失败对象 | 错误状态 |
| `Esc` | 关闭抽屉 / 对话框 / 停止当前试听 | 全局 |
| `Tab` / `Shift+Tab` | 按视觉顺序移动焦点 | 全局 |

### 1.5 焦点

- 顶部 Tab 按视觉顺序进入焦点；当前 Tab 有选中态。
- 抽屉打开后焦点进入抽屉标题 / 第一个可编辑控件；关闭后焦点返回触发按钮。
- 主操作完成后焦点留在主操作位；结果条出现时不抢焦点。
- 状态行、错误和完成 toast 使用 `aria-live` 等价语义；错误不能只靠颜色。
- 所有可点击区域最小高度 44px；键盘焦点必须有 2px 可见轮廓。

### 1.6 禁用与验证

- 禁用按钮保留可见，不禁用整个页面；相邻状态行必须解释原因。
- 表单在失去焦点和提交时验证；错误显示在字段下方。
- 文件拖入时先做扩展名 / 可读性预检；具体时长、内存和模型限制由后端返回，不在 UI 臆造上限。
- 后端不可用时，已有结果仍可试听、导出；只禁用新任务。
- 能力未就绪时显示“不可用原因 + 未来动作”，不创建伪任务。

### 1.7 Stale 规则

“stale”表示输入已经改变，现有结果不再是当前输入的产物。

| 场景 | 结果处理 | 主操作 | 导出 |
|---|---|---|---|
| 配音稿件 / 音色 / 语速改变 | 旧成品标记 `旧版本` | `重新生成` | 默认禁用；溢出菜单可确认后导出旧版本 |
| BGM prompt / 模型改变 | 旧 BGM 标记 `旧版本` | `重新生成` | 默认禁用；旧版本需确认导出 |
| BGM duck gain 改变 | 不重新生成 BGM，进入 `重新混音` | `应用并重新混音` | 混音旧版本确认可导出 |
| 人声分离源文件改变 | 旧两轨标记 `旧版本` | `重新分离` | 旧版本需确认导出 |
| 音乐歌词 / 风格改变 | 旧音乐版本仍有效，作为版本保留 | `生成新版本` | 当前选中旧版本仍可导出 |
| 音色设计试听文本 / 参考音改变 | 试听标记 `已过期` | `重新生成试听` | 保存为音色禁用，直到重新试听 |

### 1.8 确认与撤销

- 确认弹窗只用于破坏性动作：清空稿件、覆盖同名音色、删除版本、替换源文件、取消并丢弃当前结果。
- 软删除 / 清空动作提供 5 秒撤销 bar：`已清空 · 撤销`、`已删除版本 v2 · 撤销`。
- 取消任务不弹全屏确认；在任务中心二次点击 `确认取消` 即可。
- 撤销期间新操作会立即提交并关闭撤销窗口。

## 2. 配音 Tab

### 2.1 状态机

```text
empty
  → editing
  → ready
  → running
  → stopping
  → complete / partial-failed
  → stale
       ↘ recoverable → running
       ↘ failed → retry
```

| 状态 | 主画布 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | 稿件空态 | `导入 / 粘贴稿件` | `还没有句子` |
| editing | 稿件可编辑 | `开始配音`，有文本后启用 | `已切分 N 句` |
| running | 句子列表可滚动、当前句高亮 | `停止` | `第 N/M 句 · 35% · 可切 Tab` |
| stopping | 当前句完成后停止 | `停止中…` 禁用 | `正在结束当前句…` |
| complete | 句子行 + 结果条 | `再生成一版` | `M/M 完成 · 成品 03:42` |
| partial-failed | 失败句在列表前排 | `继续配音` | `1 句失败 · 其余已完成` |
| stale | 输入已改，旧成品标记旧版本 | `重新生成` | `输入已变更，旧成品为旧版本` |
| recoverable | 保留完成句 | `继续配音` | `上次完成 19/34` |

### 2.2 可点击区域与点击行为

| 区域 | 点击 / 二次点击 | 键盘 | 禁用条件 |
|---|---|---|---|
| 稿件输入区 | 聚焦编辑；拖入 `.txt` / `.md` 后替换并提示确认 | `Cmd/Ctrl+Enter` 开始 | running / stopping |
| 稿件 / 句子切换 | 单次切换视图 | `← / →` | running 时允许只读切换 |
| 句子行 | 第一次选中；第二次同一行试听 | `↑/↓` 选择，`Enter` 试听 | 不适用 |
| 展开行的 `试听` | 播放 / 停止 | `Space` | busy 单句 |
| 展开行的 `重录` | 只重录当前句 | `R` | 整任务运行 / 磁盘不可写 |
| 主按钮 | 开始 / 停止 / 继续 | `Cmd/Ctrl+Enter` | 见状态机 |
| 高级入口 | 打开配音高级 | `Cmd/Ctrl+,` | running 时可打开但参数只读 |
| 结果条 `导出` | 打开统一导出 | `Cmd/Ctrl+E` | stale、无成品时禁用 |

### 2.3 拖拽、取消、失败与恢复

- 拖入文本：校验编码可读；空文件校验失败，原稿件不覆盖。
- 取消：点击主按钮后进入 `stopping`，当前句完成后停止；已完成句不丢弃。
- 单句失败：错误显示在该句子行展开区的状态文本和全局状态行；`重录` 只重试该句。
- 任务级失败：服务不可用 / 磁盘不可写显示在状态行；`继续配音` 从失败句继续。
- 恢复：重启后恢复句子状态、模型、参考音、当前选中句；旧成品若存在显示为上一步结果。
- stale：编辑稿件后 300ms 显示 `输入已改，需要重新生成`；不自动删除旧成品。

## 3. BGM Tab

### 3.1 状态机

```text
empty → editing → ready → generating → mixing → complete
                                      ↘ failed-segment → retry-segment / remaining
                                      ↘ failed-mix → retry-mix
                                      ↘ stale → regenerate / re-mix
```

| 状态 | 主画布 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | prompt 空态 | `生成并混音` 禁用 | `写一段音乐描述` |
| ready | prompt 可编辑 | `生成并混音` | `等待生成` |
| generating | prompt 摘要 + 分段进度 | `停止` | `第 2/5 段 · 可切 Tab` |
| mixing | BGM 已完成，混音中 | `停止混音` | `正在按句子时间轴 duck` |
| complete | BGM / 混音结果 | `再生成一版` | `5 段 · 混音 03:42` |
| failed-segment | 已完成段保留，失败段标记 | `重试失败段` | `第 3 段失败` |
| failed-mix | BGM 保留，混音失败 | `重新混音` | `混音失败：<原因>` |
| stale | prompt 或模型变了 | `重新生成` | `当前结果是旧版本` |

### 3.2 点击、二次点击与高级 duck

- `prompt`：单次点击聚焦；编辑后不再自动生成。
- 主按钮：运行中第二次点击 = 停止；停止发生在当前分段完成后。
- 结果轨：第一次点击选中 `BGM` 或 `混音`；第二次点击已选中轨 = 试听。
- `高级`：打开生成、混音、导出三组。
- `duck gain`：拖动滑杆只更新当前草稿与语义值（弱 / 中 / 强），不立即重算；点击 `应用并重新混音` 后运行混音任务并自动收起抽屉。
- `混音源` 未就绪：duck 组可见但禁用，并说明“需要先完成配音成品”。
- 失败重试：生成失败按分段重试；混音失败只重试混音，不重新生成 BGM。
- 取消：停止后保留已完成段；再次点击准备继续时从第一个未完成段开始。
- stale：prompt 改变后旧 BGM 标记旧版本；如果只改 duck，则旧 BGM 仍有效，只重新混音。

## 4. 人声分离 Tab

### 4.1 状态机与能力门控

```text
empty → validating → ready → separating → complete
                               ↘ failed → retry-task
capability = ready | unsupported | error
unsupported: empty / validating 可操作，但不能进入 separating
```

| 状态 | 拖入区 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | 可点击 / 拖入 | `选择音频` | `wav / mp3 / flac` |
| validating | 文件名 + 校验中 | `校验中…` 禁用 | `只做扩展名和可读性预检` |
| ready | 文件名、格式、大小摘要 | `分离人声 / 伴奏` | `源文件已就绪` |
| separating | 文件摘要 + 阶段进度 | `停止` | `分离中 42% · 可切 Tab` |
| complete | 人声 / 伴奏两轨 | `重新分离` | `两轨已生成` |
| failed | 保留源文件 | `重试` | `解码失败 / 模型不可用 / 磁盘不足` |
| unsupported | 可选择但不可分离 | `分离人声 / 伴奏` 禁用 | `后端能力未接入，不会创建任务` |

### 4.2 点击、拖拽、键盘与取消

- 拖拽：`dragenter` 高亮拖入区；`drop` 后只读取文件元数据，不立刻上传执行。
- 点击拖入区：打开文件选择；选择后进入 `validating`。
- 结果轨：第一次点击选中 `vocals` 或 `accompaniment`；第二次点击同一轨试听。
- 键盘：`V` 选择 vocals，`A` 选择 accompaniment，`Space` 播放 / 暂停，`R` 重试。
- 取消：点击 `停止`，当前任务进入 `cancelled`；源文件保留，临时两轨不作为完成结果。
- 失败粒度：整个分离任务重试，不做单轨重试；两轨必须属于同一次模型运行。
- 恢复：保存源文件路径和任务断点；重启后如果路径不可读，显示 `重新定位源文件`。
- stale：更换或重新选择源文件后，旧两轨标记旧版本；默认禁用导出，溢出菜单可确认旧版本导出。
- 能力未就绪：按钮保持可见但 disabled；任务中心不新增任务；高级抽屉模型组只读说明。

## 5. 音乐制作 Tab

### 5.1 状态机与版本

```text
empty → editing → ready → generating → version-ready
                                      ↘ failed-version
                                      ↘ cancelled-version
editing after version-ready → draft-changed → generate new version
```

| 状态 | 主画布 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | 歌词 / 风格空 | `生成音乐` 禁用 | `填写歌词和风格` |
| ready | 两个输入有值 | `生成音乐` | `可生成 v1` |
| generating | 输入摘要 + 进度 | `停止` | `生成中 35% · 可切 Tab` |
| version-ready | 版本列表 + 选中版本 | `生成新版本` | `v1 已生成` |
| failed-version | 保留输入与历史版本 | `重试当前版本` | `v2 生成失败` |
| draft-changed | 输入已改，旧版本仍有效 | `生成新版本` | `有未生成的新修改` |

### 5.2 点击、版本、取消与恢复

- 点击 `生成音乐` 创建新版本，不覆盖历史版本。
- 版本行第一次点击选中；第二次点击同一版本试听。
- `预览` 按钮播放当前版本；切换版本时停止上一版本试听。
- 取消：停止当前版本生成；半成品版本标记为 `failed / cancelled`，不进入可导出版本。
- 重试：`重试当前版本` 使用同一输入和同一 seed 重跑；`生成新版本` 使用新 seed。
- stale：歌词 / 风格变化只标记草稿已更新，不使旧版本失效；导出默认导出当前选中的完整版本。
- 恢复：历史完整版本、选中版本、未完成版本状态均持久化。
- 删除版本：第一次点击打开确认，第二次确认删除；软删除并保留 5 秒撤销。

## 6. 音色设计 Tab

### 6.1 状态机与能力门控

```text
empty → ready → preview-running → preview-ready
                                  ↘ preview-stale
                                  ↘ saving → saved
capability-voice-library = ready | unsupported | error
unsupported: preview-running / preview-ready 可用，saving / use-in-dub / preset 不可用
```

| 状态 | 主画布 | 主按钮 | 状态行 |
|---|---|---|---|
| empty | 试听文本已填，基础音色 / 参考音未选 | `生成试听` 禁用 | `选择基础音色或参考音频` |
| ready | 文本 + 基础音色或参考音 | `生成试听` | `可生成一条试听` |
| preview-running | 输入摘要 + 进度 | `停止` | `生成试听中` |
| preview-ready | 试听结果 + 音色摘要 | `创建音色` | `试听完成 · 可保存` |
| preview-stale | 旧试听标记过期 | `重新生成试听` | `输入已改，请重新试听` |
| saved | 音色资产卡 | `再生成一版` | `已保存，可用于配音` |
| failure | 保留输入 | `重试` | `参考音频不可读 / 模型不可用 / 保存失败` |
| unsupported | 试听可用，保存区禁用 | `生成试听` | `可试听；音色库保存待 P4` |

### 6.2 点击、拖拽、键盘和高级抽屉

- `试听文本` 默认预填，单次点击聚焦；编辑后旧试听立即标记 stale。
- 基础音色：点击下拉选择；参考音频：点击选择或拖入文件。
- 参考音频拖入后显示文件名、格式和可读性；路径不可读时不进入 ready。
- `生成试听`：运行中第二次点击 = 停止；完成后的主按钮变为 `创建音色`。
- 结果条：`试听` 单次播放 / 再次点击停止；`保存为音色` 受 P4 能力门控；`预设` 菜单包含导出 / 导入，未实现时禁用。
- 高级抽屉最多三组：
  1. 基础音色 / 模型；
  2. 参考音频与参考文本；
  3. 风格 / 情绪 / seed。
- 只有后端真实支持的字段可编辑；否则显示未就绪说明，不展示假滑杆。
- 取消：停止试听生成；已生成试听保留但标记未完成 / 不可保存。
- 失败重试：试听失败重试试听；保存失败只重试保存，不重新生成试听。
- 保存后：音色资产在当前工程内持久化；同名覆盖前二次确认；删除音色可撤销。

### 6.3 “用于配音”的精确行为

P4 能力为 `ready` 时：

1. `创建音色` 保存成功，结果条出现 `用于配音`。
2. 点击 `用于配音`：
   - 切换到配音 Tab；
   - 打开配音高级抽屉；
   - 焦点落在音色选择器；
   - 自动预选刚保存的音色资产；
   - 状态行显示 `已预选音色：<名称>`；
   - 不自动开始配音，不覆盖当前稿件。
3. 返回音色设计时保留原试听和已保存资产。

P4 能力为 `unsupported` 时：

- `创建音色`、`用于配音`、`预设导出 / 导入` 全部 disabled；
- 状态行说明 `单条 voice_ref 可试听，多音色保存与复用待 P4`；
- 不能通过“临时假装已保存”绕过门控。

## 7. 完整流程脚本

### 7.1 配音

1. 输入或粘贴稿件 → 主按钮 `开始配音` 启用。
2. 点击主按钮 → 抽屉自动收起，按钮变 `停止`，状态行显示 `第 1/N 句，0%`。
3. 切换到 BGM Tab → 配音任务继续，任务中心显示 `配音 · 运行中`。
4. 切回配音 → 恢复运行中的句子列表和进度。
5. 再次点击主按钮 → `停止`；状态变为 `可继续`，已完成句保留。
6. 点击 `继续配音` 或演示控制 `完成` → 结果条出现。
7. 点击 `导出` → 导出抽屉打开；选择格式和目录；确认导出后抽屉关闭并显示成功 toast。

### 7.2 BGM

1. 输入 prompt → `生成并混音` 启用。
2. 点击生成 → 按钮变 `停止`；状态显示分段进度。
3. 完成后结果区出现 `BGM` / `混音` 两轨；点击轨行两次或点击播放按钮试听。
4. 点击 `高级` → 调整 `duck` → 点击 `应用并重新混音`；抽屉自动关闭，状态显示重新混音。
5. 混音完成后点击 `导出` → 选择 `仅 BGM / 仅混音 / 全部` 并确认。

### 7.3 人声分离

1. 拖入 wav 文件 → 进入校验，显示文件名与格式。
2. 校验通过 → `分离人声 / 伴奏` 启用。
3. 点击主按钮 → 运行进度；切 Tab 不取消。
4. 完成 → 两轨出现；选择 vocals 或 accompaniment 后试听。
5. 切换 `capability = unsupported` → 新任务主按钮禁用，状态说明后端未接入；无伪任务。
6. 切回 `ready` → 已完成的旧结果仍可试听 / 导出，新任务重新启用。

### 7.4 音乐制作

1. 输入歌词和风格 → `生成音乐` 启用。
2. 点击生成 → 运行中切换 Tab，任务中心显示 `音乐制作 · 生成中`。
3. 完成 → 出现 `v1` 版本并自动选中。
4. 修改歌词 → 旧 v1 仍有效，状态显示 `有未生成的新修改`。
5. 再点击生成 → 创建 `v2`，自动选中新版本。
6. 点击 `导出` → 导出当前选中版本。

### 7.5 音色设计

1. 试听文本已预填；选择基础音色，或拖入参考音频。
2. 点击 `生成试听` → 按钮变 `停止`，状态显示生成中。
3. 完成后主按钮变 `创建音色`；点击结果条 `试听` 播放。
4. P4 `unsupported`：`创建音色` 和 `用于配音` 禁用，显示“可试听，多音色保存待 P4”。
5. P4 `ready`：点击 `创建音色` → 保存成功，出现 `用于配音`。
6. 点击 `用于配音` → 跳转配音 Tab，打开高级并预选该音色；不自动开始配音。

## 8. Slint 实现验收清单

### 8.1 全局

- [ ] `INT-G-01` 五个 Tab 可用鼠标和 `Cmd/Ctrl+1..5` 切换。
- [ ] `INT-G-02` 运行中切换 Tab 不调用 stop/cancel callback。
- [ ] `INT-G-03` 主操作运行时，同一位置文案变为 `停止`，其他主操作不并列出现。
- [ ] `INT-G-04` 抽屉关闭后焦点回到打开抽屉的按钮。
- [ ] `INT-G-05` 任务中心显示来源 Tab、状态、进度和可用动作。
- [ ] `INT-G-06` 取消按钮需要二次点击确认，取消后状态是 recoverable。
- [ ] `INT-G-07` 重启后 running 任务变成“已中断，可继续”，不会保持转圈假运行。
- [ ] `INT-G-08` 禁用按钮可见，并且相邻状态行或 tooltip 给出原因。
- [ ] `INT-G-09` 编辑已生成结果后，stale 标记在 300ms 内出现。
- [ ] `INT-G-10` 清空、删除、覆盖动作支持确认与 5 秒撤销。

### 8.2 配音

- [ ] `INT-DUB-01` 空稿 `开始配音` disabled；有稿后启用。
- [ ] `INT-DUB-02` 点击开始后按钮变 `停止`，状态行显示当前句号与百分比。
- [ ] `INT-DUB-03` 运行中切 Tab 后返回，句子状态和进度不丢。
- [ ] `INT-DUB-04` 停止后已完成句保留，主按钮变为 `继续配音`。
- [ ] `INT-DUB-05` 单句失败显示在该行，`重录` 仅触发单句重试。
- [ ] `INT-DUB-06` 稿件或音色变化后旧成品标 `旧版本`，默认导出禁用。
- [ ] `INT-DUB-07` 结果完成且未 stale 时，导出抽屉可导出 WAV / SRT。

### 8.3 BGM

- [ ] `INT-BGM-01` 空 prompt 时 `生成并混音` disabled。
- [ ] `INT-BGM-02` 运行中再次点击主按钮停止，已完成分段保留。
- [ ] `INT-BGM-03` 完成后切轨选中、再次点击播放。
- [ ] `INT-BGM-04` duck 改变只标记重新混音草稿，点击应用后才运行混音。
- [ ] `INT-BGM-05` 分段失败只提供 `重试失败段`，不重做已完成段。
- [ ] `INT-BGM-06` 混音失败只提供 `重新混音`，不重新生成 BGM。
- [ ] `INT-BGM-07` prompt 变化后旧 BGM stale，导出需确认旧版本。

### 8.4 人声分离

- [ ] `INT-SEP-01` 拖入或选择 wav/mp3/flac 后进入 validating。
- [ ] `INT-SEP-02` 扩展名或可读性失败时显示字段错误，不创建任务。
- [ ] `INT-SEP-03` 校验通过后主按钮启用；运行中变 `停止`。
- [ ] `INT-SEP-04` 结果区有 vocals / accompaniment 两轨，可分别选中和试听。
- [ ] `INT-SEP-05` capability unsupported 时主按钮 disabled 且状态说明具体原因。
- [ ] `INT-SEP-06` unsupported 时不创建任务，也不显示假模型 / 假阈值。
- [ ] `INT-SEP-07` 失败重试粒度是整任务，不提供单轨重试。
- [ ] `INT-SEP-08` 重开应用后源文件可恢复；文件丢失显示重新定位。

### 8.5 音乐制作

- [ ] `INT-MUS-01` 歌词或风格为空时 `生成音乐` disabled。
- [ ] `INT-MUS-02` 每次成功生成创建新版本，不覆盖旧版本。
- [ ] `INT-MUS-03` 版本行第一次选中、第二次播放，切换版本停止旧播放。
- [ ] `INT-MUS-04` 修改歌词 / 风格后旧版本仍可导出，草稿显示有新修改。
- [ ] `INT-MUS-05` 取消当前版本生成不影响历史完整版本。
- [ ] `INT-MUS-06` 重试当前版本复用输入和 seed；生成新版本使用新 seed。
- [ ] `INT-MUS-07` 删除版本经过二次确认并可 5 秒撤销。

### 8.6 音色设计

- [ ] `INT-VOI-01` 试听文本默认有值；基础音色 / 参考音频未选时主按钮 disabled。
- [ ] `INT-VOI-02` 选择基础音色或有效参考音频后 `生成试听` 启用。
- [ ] `INT-VOI-03` 运行中主按钮变 `停止`，试听文本等输入 disabled。
- [ ] `INT-VOI-04` 试听完成后主按钮变 `创建音色`。
- [ ] `INT-VOI-05` 修改试听文本 / 基础音色 / 参考音后试听 stale，保存 disabled。
- [ ] `INT-VOI-06` P4 unsupported 时 `创建音色`、`用于配音`、预设操作 disabled，并显示原因。
- [ ] `INT-VOI-07` P4 ready 时保存成功后出现 `用于配音`。
- [ ] `INT-VOI-08` 点击 `用于配音` 跳转配音 Tab、打开高级抽屉、聚焦并预选刚保存的音色，且不自动开始。
- [ ] `INT-VOI-09` 参考文本、风格、情绪、seed 只有后端真实支持时才可编辑，否则只读未就绪。
