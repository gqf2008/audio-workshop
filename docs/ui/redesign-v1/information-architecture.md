# 音频作坊 · UI Redesign v1 信息架构

> 设计输入：`CHARTER.md`、`docs/product-plan.md`、`docs/ui/首屏清单.md`、当前 `ui/app.slint` / `ui/dub_workbench.slint` / `ui/bgm_workbench.slint`，以及 `feat/m4-song` 分支的 `ui/song_workbench.slint`。  
> 范围：只定义产品、交互和信息架构，不修改 Rust / Slint 实现，不提交代码。  
> 核心目标：顶部四场景导航清晰；每屏只有一个主任务；参数渐进披露；主画布低密度；状态和任务可恢复。

## 1. 一级信息架构

```text
音频作坊
├─ 顶部主 Tab（始终可见，不放进抽屉）
│  ├─ 配音
│  ├─ BGM
│  ├─ 人声分离
│  └─ 音乐制作
│
├─ 全局项目条
│  ├─ 当前工程 / 场景对象
│  ├─ 保存与恢复状态
│  └─ 任务中心入口
│
├─ 当前 Tab 的单任务画布
│  ├─ 1 个主对象（稿件、prompt、音频轨、歌词等）
│  ├─ 1 个主操作
│  ├─ 1 行可恢复任务状态
│  └─ 结果就绪时再出现 1 个结果区
│
├─ 当前 Tab 的高级抽屉
│  ├─ 模型 / 音色 / 算法阈值
│  ├─ 时长 / 步数 / gain / 分段
│  └─ 当前场景专属导出选项
│
└─ 全局从属面板（不属于任何主 Tab）
   ├─ 任务中心：跨 Tab 查看、取消、重试、恢复、回到来源 Tab
   ├─ 全局设置：主题、存储目录、服务状态、关于
   └─ 统一导出：根据当前结果类型显示可用产物
```

顶部横向 Tab 是唯一的一级导航。工程、任务、导出、设置都不能取代或隐藏这四个入口。

## 2. 四个 Tab 的职责边界

| Tab | 用户问题 | 输入 | 输出 | 可依赖对象 | 不负责 |
|---|---|---|---|---|---|
| 配音 | “把这段稿变成可校听的人声” | 稿件文本、句子修改、已选音色 | 逐句语音、配音成品、字幕时间轴 | 当前工程、音色资产 | BGM 生成、混音、人声分离、歌曲制作 |
| BGM | “给这条内容生成并混好背景音乐” | 音乐描述、可选混音来源 | BGM 成品、配音+BGM 混音、可选分轨 | 配音成品（仅混音时需要）、BGM 资产 | 修改稿件、校听人声句子、人声分离 |
| 人声分离 | “把一段音频拆成人声和伴奏” | 本地音频文件、分离设置 | 人声轨、伴奏轨 | 当前工程，或新建独立音频资产 | 配音合成、BGM 生成、歌曲生成 |
| 音乐制作 | “从歌词和风格生成一首歌” | 歌词、风格描述 | 歌曲成品、导出文件 | 当前工程、音乐模型 | 配音句子状态、BGM ducking、人声分离 |

### 2.1 边界规则

1. **一个 Tab 一次只完成一个主任务。** BGM 的“生成”和“混音”属于同一条主任务链，不作为两个并列主按钮。
2. **跨 Tab 只通过工程资产连接。** 例如 BGM 只能读取“当前工程里的配音成品”，不在 BGM 页修改配音句子。
3. **切 Tab 不自动启动、不自动取消任务。** 正在运行的任务留在全局任务中心，切换后继续运行。
4. **失败必须可回到来源。** 任务中心中的失败项可以一键回到所属 Tab，并定位到可重试对象。
5. **能力未实现不能伪装。** 人声分离在模型/后端未落地前只显示明确的能力未就绪态，不伪造算法名、模型名或阈值选项。

## 3. 共享对象与工程模型

### 3.1 产品侧统一对象

```text
WorkspaceProject
├─ identity: id / name / revision / created_at / updated_at
├─ assets
│  ├─ script: 稿件文本、切句版本、句子状态
│  ├─ voice_master: 配音成品、逐句音频、字幕
│  ├─ bgm_master: BGM 成品、混音成品、分轨
│  ├─ separation_set: 源音频、人声轨、伴奏轨
│  └─ music_master: 歌词、风格、歌曲成品
├─ tasks: 所有异步任务记录
├─ exports: 导出预设、输出目录、最近导出结果
└─ ui_state: 当前 Tab、上次选中对象、抽屉分组
```

### 3.2 对象规则

| 对象 | 归属 | 生命周期 | 主要消费者 |
|---|---|---|---|
| 工程 | 全局 | 持久化，可恢复 | 四个 Tab、任务中心、导出 |
| 资产 | 工程 | 生成后持久化，可被多个 Tab 引用 | 当前 Tab、混音、导出 |
| 任务 | 工程 | 排队、运行、完成、失败、取消；中断后恢复 | 任务中心、所属 Tab |
| 导出预设 | 工程或全局默认 | 可保存 | 统一导出面板 |
| UI 状态 | 工程 | 保存当前 Tab、选中对象、抽屉状态 | 恢复上次工作现场 |

### 3.3 与现有实现的边界

当前 `project.json` 主要承载配音句子和逐句合成状态；BGM 产物在运行时对象中管理。Redesign v1 要求 UI 把它们统一成“工程资产 + 任务记录”的产品模型，但**不要求这一轮设计直接决定后端存储格式**。实现阶段可以选择：

- 扩展同一个工程 manifest；或
- 保留各链路现有 manifest，在 UI 层维护统一的 `ProjectView`。

无论采用哪种方式，外部行为必须一致：切 Tab 不丢状态，重开应用能看到上次结果，失败任务能重试，导出只读取同一工程版本的产物。

## 4. 导航与状态规则

### 4.1 顶部导航

- 四个 Tab 横向排列，始终可见，默认当前 Tab 有明确选中态。
- Tab 不因任务运行、空态、失败态而消失。
- Tab 右侧只显示轻量状态：运行中转圈、失败点、完成态不常驻。
- 不使用“场景选择页”“启动页”或抽屉里的二级场景切换替代顶部 Tab。
- 音乐制作可以带“实验性”短标签，但不能把模型选择或质量长文放到主导航上。

### 4.2 Tab 内状态机

```text
empty
  → editable
  → queued
  → running
  → reviewable
  → complete
       ↘ failed → retry → queued
       ↘ cancelled → resume → queued
```

| 状态 | 主画布 | 主操作 | 状态行 | 可跨 Tab |
|---|---|---|---|---|
| empty | 空态 + 唯一下一步 | 导入 / 创建 / 生成 | 一句说明 | 是 |
| editable | 当前主对象可编辑 | 开始主任务 | 保存状态 | 是 |
| queued | 保留输入摘要 | 取消 | 排队位置 | 是 |
| running | 展示阶段与进度，不铺参数 | 停止 / 暂停（按能力） | 当前阶段 + 可恢复 | 是 |
| reviewable | 结果可试听、对比、重录 | 确认 / 重新生成 | 待确认项数 | 是 |
| complete | 结果摘要 + 导出入口 | 再次生成 / 导出 | 产物与目录 | 是 |
| failed | 失败原因 + 可重试对象 | 重试 | 错误摘要 | 是 |

### 4.3 任务中心规则

- 全局任务中心展示所有 Tab 的任务，按“运行中 → 等待中 → 失败 → 最近完成”排序。
- 一个 Tab 只允许一个前台主任务；多个任务进入全局串行队列，避免本地模型并发抢显存。
- 任务记录至少包含：来源 Tab、任务类型、输入摘要、进度、结果资产、恢复点和失败原因。
- 重试必须使用同一工程版本和同一输入；如果工程已变更，先提示“重新生成”而不是静默复用。
- 切换 Tab、关闭抽屉、进入全屏都不应取消任务。

### 4.4 抽屉与二级页规则

- 抽屉只服务当前主任务，标题随 Tab 改变，例如“配音设置”“BGM 高级”“分离高级”“音乐高级”。
- 抽屉最多 3 组：
  1. 必需但低频的对象设置；
  2. 算法 / 模型参数；
  3. 导出或交付设置。
- 每个 Tab 的首屏只保留一个“高级”入口。打开后不增加主画布常驻元素。
- 全局设置与当前场景高级设置分开，避免主题、工程、导出、模型全部塞进一个“工作台设置”。

### 4.5 导出规则

- 导出不是第五个主 Tab，也不占据四 Tab 之一。
- 无有效结果时，导出入口不可见或明确禁用并说明原因。
- 有结果后，结果区出现“导出”次操作；点击进入统一导出抽屉。
- 导出文件名沿用工程名和产物类型；配音、BGM、分离、音乐分别只展示自己可用的格式。
- 默认导出参数最少：格式 + 目录。批量、分轨、模板等低频能力放导出抽屉或二级页。

## 5. 密度治理红线

### 5.1 计数口径

本设计使用“语义元素计数”，不是控件行数，也不是所有子部件数量：

- 顶部四个 Tab 计为 **1 个导航组**。
- 项目条、任务条、主画布、主操作、结果区、高级入口各计 1。
- 文本域内部的边框、图标、状态点、滚动条不计独立元素。
- 列表的多行只计 1 个列表对象。
- 默认隐藏的抽屉、二级页、选中后才展开的行内操作不计入首屏。
- 窗口系统控件（最小化/最大化/关闭）不计入产品首屏元素。

### 5.2 硬指标

| 指标 | 上限 | 适用 |
|---|---:|---|
| 首屏语义元素 | ≤ 8 | 每个 Tab |
| 主操作 | 1 | 每屏、每种稳定状态 |
| 可见参数输入 | 配音 0；BGM 1；人声分离 1；音乐制作 2 | 默认首屏 |
| 高级参数常驻 | 0 | 所有 Tab |
| 首屏实现参数 | 0 | seed、毫秒、时间轴刻度、步数、模型名等 |
| 常驻数字读数 | ≤ 1 | 只在结果/状态需要时出现 |
| 高级抽屉分组 | ≤ 3 | 每个 Tab |
| 并列操作 | ≤ 3 | 任意一行 |
| 点击目标高度 | ≥ 44px | 主要交互 |

### 5.3 参数归属

| 参数 | 默认位置 | 说明 |
|---|---|---|
| 音色、语速、参考音、数字规范化 | 配音高级 | 首屏不显示 |
| BGM 时长、duck gain、分段、模型 | BGM 高级 | 首屏只显示 prompt 与结果 |
| 分离模型、阈值、降噪、输出格式 | 人声分离高级 | 后端能力未落地前不展示假选项 |
| 音乐模型、步数、时长、语言 | 音乐制作高级 | 模型选择从当前歌曲首屏移走 |
| seed | 高级或任务详情 | 不作为普通用户首屏信息 |
| 毫秒、时间轴刻度、引擎内部版本 | 设置 / 任务详情 / 诊断 | 不进入首屏 |
