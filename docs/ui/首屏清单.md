# 首屏清单与计数口径（低密度版）

本文件给出**可复现**的「首屏组件数」口径与命令，以及间距的实际数值。
截图（`01-default.png` … `04-dark.png`）是上一版基线，新增简化版落地后待重拍。

## 一、计数口径

**首屏 = 默认态（示例稿已切句、没有选中句子、右侧抽屉收起）下屏幕上看得到的元素。**

1. **按元素计，不按子部件计**：一个元素内部的文字、状态点、窗口按钮等都算在它自己身上。
   - 标题栏（logo + 标题 + 最小化/最大化/关闭）= 1
   - 状态栏（状态文本 + 引擎名）= 1
   - 句子列表（滚动区 + 行模板「序号 + 文本 + 状态点」）= 1（列表行不乘以行数）
2. **布局容器、留白、分隔线、状态点等纯装饰不计**。
3. **只在别的状态下才出现的元素不计入默认态**：抽屉里的全部内容（默认收起）、
   句子行展开后的「试听 / 重录」、空稿态的引导按钮——后两者单独用 `// 首屏-空态` 标注并另算。

标注方式：每个首屏元素在**声明行行尾**带 `// 首屏`；空稿态额外出现的元素带 `// 首屏-空态`。

## 二、可复现命令与输出

```console
$ grep -c '// 首屏$' ui/*.slint
ui/app.slint:4
ui/dub_workbench.slint:5
ui/model.slint:0

$ grep -h '// 首屏$' ui/*.slint | wc -l
9

$ grep -c '// 首屏-空态$' ui/*.slint
ui/app.slint:0
ui/dub_workbench.slint:2
ui/model.slint:0
```

- **默认态首屏 = 9 个 ≤ 12**（红线达标）。
- **空稿态 = 9 − 1（列表消失）+ 2（空态提示与「载入示例稿」）= 10 个 ≤ 12**（同样达标）。

## 三、默认态首屏的 9 个元素（逐条给出源码位置）

| # | 元素 | 位置 |
|---|------|------|
| 1 | 标题栏（外壳：logo / 标题 / 最小化 / 最大化 / 关闭） | `ui/app.slint:118` |
| 2 | 场景 tab（配音 / BGM） | `ui/app.slint` 顶栏下方 |
| 3 | 抽屉开关（三横条，展开右侧抽屉） | `ui/app.slint:131` |
| 4 | 稿件输入域 | `ui/dub_workbench.slint:419` |
| 5 | 清空（并进输入域右上角的小图标） | `ui/dub_workbench.slint:429` |
| 6 | 状态行：句数 · 已合成句数 | `ui/dub_workbench.slint` 状态行 |
| 7 | 开始合成 / 停止合成 / 停止试听（首屏主入口） | `ui/dub_workbench.slint` 主按钮 |
| 8 | 句子列表（滚动区 + 行模板：序号 + 文本 + 状态点） | `ui/dub_workbench.slint` 列表区 |
| 9 | 状态栏（外壳：状态文本 / 引擎名） | `ui/app.slint:198` |

空稿态额外出现（列表消失、这两个元素出现，共 10 个）：

音色 / 语速 / 数字规范化、任务进度 / 试听全篇、导出格式 / 开始导出 / 输出目录。

## 四、间距实际数值

| 位置 | 值 | 出处 |
|------|----|------|
| 句子行高 | 48px（选中展开 92px = 48 + 44） | `ui/dub_workbench.slint:51` |
| 首屏内容区块之间 | 20px | `ui/dub_workbench.slint:413` |
| 首屏内容区块**内** | 16px | `:418` `:459` `:489` |
| 句子行内（序号 ↔ 文本） | 16px | `:83` |
| 句子展开行内（状态 ↔ 试听 ↔ 重录） | 16px | `:120` |
| 抽屉区块之间 | 20px | `:208` |
| 抽屉区块**内** | 16px | `:213` `:227` `:248` `:262` `:287` `:305` `:307` |
| 同级并列元素 | 每行 ≤ 3（状态行 3、展开行 3、抽屉状态行 3） | 见截图 |

例外与说明（都不属于「内容区块」）：

- `ui/app.slint:115` `spacing: 0px`：标题栏 / 内容区 / 状态栏是窗口外壳的上下堆叠，
  内容区自带 20px 内边距，0 间距是外壳贴边，不是区块间距。
- `ui/dub_workbench.slint:508` `spacing: 0px`：句子列表的行间用 1px 分隔线，行与行紧排。
- `ui/dub_workbench.slint:34` `letter-spacing`：字距，与布局间距无关。
- 组件库 `PixelDrawer` 内部「标题栏 ↔ 内容」自带 10px，属于第三方组件内部值，本仓库未改。

## 五、密度指标（原 grep，仅作前后对比，不是本文件的计数口径）

```console
$ grep -cE 'Pixel(Panel|Button|Stat|Badge|Tag|CheckBox|Slider|Switch|ComboBox)' ui/*.slint
ui/app.slint:0
ui/dub_workbench.slint:11
ui/model.slint:0
```

改前 32 → 改后 11。这一条只数「大块控件」，**不含**外壳组件与纯文本，
所以它只用来描述控件密度的变化，首屏是否达标以第二节的命令为准。
