# 首屏清单与计数口径（v1.4 五 Tab 版）

本文件给出**可复现**的「首屏组件数」口径与命令，以及间距的实际数值。

对应的设计依据：`docs/ui/redesign-v1/screens.md`（每屏 ≤8 个语义元素、恰好 1 个主操作、
默认 0 个高级参数）与 `docs/ui/redesign-v1/interaction-spec.md`（逐条交互验收）。
截图基线与可点击原型见 `docs/ui/redesign-v1/`。

> 说明：本目录的 `01-default.png` … `04-dark.png` 是**低密度版**（v1.2 之前）的历史基线，
> v1.4 五 Tab 版尚未重拍。原因不是渲染问题：本机 ToDesk 远控会注入幽灵鼠标点击
> （见 `LESSON_ToDesk注入幽灵鼠标点击污染Bevy客户端UI验证.md`，同样打在本窗口上），
> 会把顶部 Tab 随机切走，抓不到确定的「默认态」基线。
> 重拍前请以 `docs/ui/redesign-v1/wireframes-preview.png` 与 `interactive-prototype.html` 为准。

## 一、计数口径

**首屏 = 默认态（示例稿已切句、没有选中句子、音色选择器与右侧抽屉都收起）下屏幕上看得到的元素。**

1. **按语义元素计，不按子部件计**：一个元素内部的文字、状态点、窗口按钮等算在它自己身上。
   - 标题栏（logo + 标题 + 抽屉开关 + 最小化/最大化/关闭）= 1
   - 顶部 5 个主 Tab（配音 / BGM / 人声分离 / 音乐制作 / 音色设计）= 1 个导航组
   - 旁白块（块头「当前音色 + 来源 + 试听/换音色/新建音色」+ 块体稿件）= 1
   - 句子列表（滚动区 + 行模板「序号 + 文本 + 状态点」）= 1（列表行不乘以行数）
2. **布局容器、留白、分隔线、状态点等纯装饰不计**。
3. **只在别的状态下才出现的元素不计入默认态**：抽屉与音色选择器全部内容（默认收起）、
   句子行展开后的「试听 / 重录」、空稿态的引导按钮——后两者用 `// 首屏-空态` 标注并另算。
4. **页面标题 / 说明文字不计元素**：Tab 条已经标了页名，标题只是重复标签
   （配音页没有标题元素，两页口径因此一致）；但**任务状态行计入**（它是状态出口，不是装饰）。
5. **本文件的计数范围是「外壳 + 配音 Tab 与音乐制作 Tab」**：`// 首屏` 标记落在这两处（外壳 3 + 配音 5 = 8）。
   其他 Tab 另算：「人声分离」是整屏占位（不计元素数）；「音乐制作」按同一口径
   **默认态 5 个（歌词 / 风格 / 生成 / 高级 / 状态行）+ 外壳 3 = 8**；
   有成品时状态行并进「结果条」，仍是 **5 + 3 = 8**，达标。
   它的「引擎（yue2 / ACE-Step）」在本页「高级」里，`试听` / `导出 WAV` 合并进结果条。

标注方式：每个首屏元素在**声明行行尾**带 `// 首屏`；空稿态额外出现的元素带 `// 首屏-空态`。

## 二、可复现命令与输出

标记按"每屏"读，不要拿全局总数直接下结论（`app.slint` 的 3 个外壳元素被各 Tab 共用）：

```console
$ grep -c '// 首屏$' ui/*.slint
ui/app.slint:3              # 外壳：标题栏 / 顶部五 Tab / 状态栏（各 Tab 共用）
ui/bgm_workbench.slint:0
ui/dub_workbench.slint:5    # 配音页
ui/extra_tabs.slint:0
ui/model.slint:0
ui/song_workbench.slint:5   # 音乐制作页
ui/voice_picker.slint:0

$ grep -h '// 首屏$' ui/*.slint | wc -l
13                          # 3 + 5 + 5，跨屏相加，不是任何一屏的元素数

$ grep -c '// 首屏-空态$' ui/*.slint
ui/app.slint:0
ui/bgm_workbench.slint:0
ui/dub_workbench.slint:2
ui/extra_tabs.slint:0
ui/model.slint:0
ui/song_workbench.slint:0
ui/voice_picker.slint:0
```

- **配音页：默认态 3 + 5 = 8 ≤ 8**（v1.4 红线达标）。
- **配音页空稿态 = 8 − 1（列表消失）+ 2（空态提示与「载入示例稿」）= 9**，其中「句子列表」消失后
  主操作也因无句子而禁用，仍然是每屏一个主操作。
- **音乐制作页：默认态 3 + 5 = 8 ≤ 8**；结果就绪时状态行并进结果条，仍是 8。

## 三、默认态首屏的 8 个元素（逐条给出源码位置）

| # | 元素 | 位置（按名字定位，不写行号） |
|---|------|------|
| 1 | 标题栏（logo / 标题 / 抽屉开关 / 最小化 / 最大化 / 关闭） | `ui/app.slint` 主窗口 `VerticalLayout` 第一子项 |
| 2 | 顶部 5 个主 Tab（配音 / BGM / 人声分离 / 音乐制作 / 音色设计） | `ui/app.slint` 的 `PixelTabs` |
| 3 | 旁白块（块头＝当前音色 + 试听 / 换音色；块体＝稿件；音色区在块内展开） | `ui/dub_workbench.slint` 的 `DubWorkbench` 内带 `// 首屏` 的 `Rectangle` |
| 4 | 状态行：句数 · 已合成句数 | 同上，`Text { // 首屏 }` |
| 5 | 高级入口（展开配音页内的高级区） | 同上，第一个小号 `PixelButton { // 首屏 }` |
| 6 | 主操作：开始合成 / 停止合成 / 停止试听 | 同上，`variant: "primary"` 的 `PixelButton { // 首屏 }` |
| 7 | 句子列表（滚动区 + 行模板：序号 + 文本 + 状态点） | 同上，`PixelScrollPanel { // 首屏 }` |
| 8 | 状态栏（状态文本 / **任务 chip** / 引擎名；当前音色在旁白块头与页内音色区，不在状态栏） | `ui/app.slint` 主窗口 `VerticalLayout` 最后子项 |

复现（比行号稳）：

```console
# 首屏元素总数（外壳 3 + 配音页 5 = 8）
grep -h '// 首屏$' ui/*.slint | wc -l

# 逐条看是哪 8 个
grep -n '// 首屏$' ui/*.slint

# 音乐制作页（scene 3）：默认态 5 个；结果就绪时状态行并进结果条，仍是 5 个
grep -c '// 首屏$' ui/song_workbench.slint          # 5（含状态行）
grep -n '// 首屏-结果就绪$' ui/song_workbench.slint   # 1（结果条）
```

> 抽屉开关并进 #1 标题栏（它是标题栏内的自绘三横条），不单列。
> #5 展开后的高级区是**渐进披露**，默认不显示，所以不计入默认态。

> #3 是 v1.4 相对旧版新增的**一等语义元素**：当前音色从抽屉里提到旁白块头，
> 直接回答「配音没有选择音色的地方」。块内的三个按钮不再各算一个元素。

**设置放哪儿（全局 vs 独有）**：全局设置（外观、工程名、服务地址/端口、模型目录）在右上角抽屉「全局设置」里；
配音独有的参数（重新切句 / 倍速 / 数字规范化 / 任务进度 / 导出格式与目录）在配音页
自己的「高级」区里（#5 展开）。判断口径：换一个 Tab 这条设置还成立吗？成立就是全局。

空稿态额外出现（列表消失、这两个元素出现，带 `// 首屏-空态` 标记）：
`ui/dub_workbench.slint` 里 `DubWorkbench` 内的空态 `VerticalLayout`（提示文案）、
其内的「载入示例稿」`PixelButton`。复现：`grep -n '// 首屏-空态$' ui/*.slint`。

首屏看不到、全部藏在二级界面里的：音色选择器（搜索 / 卡片 / 试听 / 使用此音色）、
配音页内的「高级」区（重新切句 / 倍速 / 规范化 / 任务进度 / 试听全篇 / 导出）、
右上角「全局设置」抽屉（外观、工程名、服务地址/端口、模型目录）、
音色设计 Tab 的参考音频与文本生成音色。

## 四、间距实际数值

| 位置 | 值 | 出处（组件/属性名） |
|------|----|------|
| 句子行高 | 48px（选中展开 92px = 48 + 44） | `SentenceRow` 的 `height` |
| 首屏内容区块之间 | 20px | `DubWorkbench` 内容列 `VerticalLayout.spacing` |
| 首屏内容列内边距 | 上 20px / 下 16px | 同上 `padding-top` / `padding-bottom` |
| 旁白块内（块头 ↔ 音色区 ↔ 稿件） | 10px | 旁白块内层 `VerticalLayout.spacing` |
| 旁白块内边距 | 12px | 同上 `padding` |
| 句子行内（序号 ↔ 文本） | 16px | `SentenceRow` 主行 `HorizontalLayout.spacing` |
| 句子展开行内（状态 ↔ 试听 ↔ 重录） | 16px | `SentenceRow` 展开行 `HorizontalLayout.spacing` |
| 抽屉区块之间 | 20px | `WorkbenchDrawer` 内容列 `VerticalLayout.spacing` |
| 抽屉区块**内** | 16px | 各分组 `VerticalLayout.spacing` |
| 同级并列元素 | 每行 ≤ 3（状态行 3、展开行 3、抽屉状态行 3） | 见截图 |

例外与说明（都不属于「内容区块」）：

- `ui/app.slint` 外壳的 `spacing: 0px`：标题栏 / Tab 行 / 内容区 / 状态栏是窗口外壳的上下堆叠，
  内容区自带 20px 内边距，0 间距是外壳贴边，不是区块间距。
- 句子列表内部 `spacing: 0px`：行间用 1px 分隔线，行与行紧排。
- `SectionLabel` 的 `letter-spacing`：字距，与布局间距无关。
- 全局设置卡片是自绘的（不再用组件库 `PixelDrawer`），卡片内边距 16px。

## 四点五、Body 区滚动与浮层

- **Body 区**（Tab 行与状态栏之间）整体包在 `PixelScrollPanel` 里：展开音色区 / 高级区
  后内容超过窗口高度时**出垂直滚动条**，而不是把底部状态栏顶出窗口。
  验证用例：`AW_UI_STATE=both`（音色浮层 + 高级区同时展开）。
- **音色区在旁白块内部展开**：「换音色」按钮属于旁白块，它的选择区就在**同一个块里**
  长出来（块被撑高，稿件仍在该块内），不是块外面的另一个盒子，也不是浮层。
  「高级」是页面级的盒子，两者同为"就地自然展开"、都靠上面那条 Body 滚动兜住超高。
- **任务中心入口并进状态栏**（`任务 · 配音 35%` 那枚 chip）：它是 #8 状态栏内部的元素，
  不新增首屏元素；点开的任务中心是一块浮动圆角卡片（左侧、默认收起），同样不计默认态。
- **两个浮层都下移到 Tab 行之下**（y = 80px）：早期版本 y=10 会盖住标题栏的窗口按钮与
  Tab 行，虽然功能没坏但看起来像"标题栏被吃了"。
- **全局设置抽屉是浮动圆角卡片**（自绘，不再用贴边面板）：右侧留 10px、
  上距 Tab 行 80px、底部让开 42px（状态栏可见），四周统一 8px 圆角（外圆角 10 − 描边 2），
  带 2px 描边与 × 关闭；遮罩单独裁到窗口的 10px 圆角。
  为什么不用贴边面板：窗口是「无边框 + 圆角」，贴右边、底边到状态栏的面板**上角能跟
  窗口圆角走、下角却是内直角**，视觉上「上圆下方」跟窗口打架。

## 五、窗口边框口径（参考 ../abb）

`no-frame: true` 自绘窗没有系统边框，边框由根 `Rectangle` 画：

| 项 | 值 | 出处 |
|----|----|------|
| 描边宽度 | 2px（贴窗口边） | `ui/app.slint` 根 Rectangle |
| 描边色 | 纯黑 `#000000`（`UiTokens.window-frame`） | `ui/app.slint` |
| 外圆角 | 10px | `ui/app.slint` 根 Rectangle |
| 内圈圆角 | 8px = 10 − 2（标题栏、状态栏各一处） | `ui/app.slint` |
| 外壳 padding | 2px（= 描边宽度，不让子元素盖掉描边） | `ui/app.slint` |

窗口 `background: transparent`：根 Rectangle 圆角外必须透出桌面，否则四角会露方块。
